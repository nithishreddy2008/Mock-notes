# CUET UG — Exam Overview (Common University Entrance Test (UG) 2027 Cycle)

**Authority:** National Testing Agency (NTA)  
**Official site:** https://cuet.nta.nic.in/

## Exam Pattern (from official document)

| Item | Details |
|------|---------|
| **Conducting body** | National Testing Agency (NTA), for admission to UG programs in Central, State, Deemed and Private universities |
| **Mode** | Computer-Based Test (CBT) |
| **Question type** | MCQ, one correct option |
| **Subjects allowed** | Up to 5 subjects (Language(s) + Domain subjects + General Aptitude Test) |
| **Paper structure (per subject)** | 50 compulsory questions per subject paper, 60 minutes per paper, +5 per correct answer, NO negative marking (pattern as per 2025/2026 cycle - verify 2027 bulletin when released) |
| **Languages tested in** | 13 languages (English, Hindi, Assamese, Bengali, Gujarati, Kannada, Malayalam, Marathi, Odia, Punjabi, Tamil, Telugu, Urdu) |
| **Syllabus basis** | Class 12 NCERT (strictly) for all domain subjects |

## Syllabus Basis

CUET UG domain syllabus maps strictly to NCERT Class 12. The official NTA syllabus documents define unit-wise topics per subject (subject codes, e.g. Physics-322).
