# NISER NEST — Exam Overview (National Entrance Screening Test (NEST) 2027 Cycle)

**Authority:** NISER Bhubaneswar & UM-DAE CEBS Mumbai (DAE, Govt. of India)  
**Official site:** https://www.nestexam.in/

## Exam Pattern (from official document)

| Item | Details |
|------|---------|
| **Mode** | Online computer-based test |
| **Sections** | 4 sections — Biology, Chemistry, Mathematics, Physics (60 marks each) |
| **Marking** | +3 correct, −1 wrong, 0 unanswered |
| **Scoring** | Best 3 of 4 section scores count toward total (if all 4 sections ≥ SMAS); must attempt at least 3 sections |
| **SMAS** | Section-wise Minimum Admissible Score (a section cut-off) applies per section |
| **Eligibility** | Class XII with ≥60% aggregate (unreserved) or equivalent grade; qualifying exam in 2025/2026/2027 for NEST 2027 (verify) |
| **Admissions via NEST** | 5-year Integrated MSc at NISER Bhubaneswar and UM-DAE CEBS Mumbai (DAE Centres of Excellence) |
