# COMEDK UGET — Exam Overview (COMEDK Undergraduate Entrance Test (UGET) 2027 Cycle)

**Authority:** Consortium of Medical, Engineering and Dental Colleges of Karnataka (COMEDK)  
**Official site:** https://www.comedk.org/

## Exam Pattern (from official document)

| Item | Details |
|------|---------|
| **Mode** | Online computer-based test |
| **Papers** | Single paper: Physics (60 Q) + Chemistry (60 Q) + Mathematics (60 Q) |
| **Duration** | 180 minutes (3 hours) |
| **Marking** | 1 mark per correct answer; NO negative marking |
| **Maximum marks** | 180 |
| **Eligibility** | 10+2 (Karnataka PUC or equivalent) with Physics, Chemistry, Mathematics; min 45% aggregate in PCM (40% for reserved Karnataka categories) |
| **Admissions via UGET** | B.E./B.Tech. seats in ~190 private engineering colleges in Karnataka |
