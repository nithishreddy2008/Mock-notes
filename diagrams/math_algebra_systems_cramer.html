1. Linear Systems Classification Engine
AX = B
Matrix Form Representation:
A system of linear equations is written compactly as AX = B, where A is the coefficient matrix, X is the variable vector, and B is the constant vector.
Case 1: |A| ≠ 0 (Non-Singular Matrix)
• The system is Consistent and Independent.
• Possesses a Unique Solution given by:
X = A⁻¹ B = (adj(A) · B) / |A|
Case 2A: |A| = 0 and (adj(A)) · B ≠ O
• The system is Inconsistent.
• Possesses Zero Solutions (No solution exists; planes are parallel or non-intersecting).
Case 2B: |A| = 0 and (adj(A)) · B = O
• The system is Consistent.
• Possesses Infinitely Many Solutions (Coincident planes / linearly dependent equations).
Homogeneous System AX = O: If |A| ≠ 0 ⇒ only trivial solution X = O. If |A| = 0 ⇒ non-trivial solutions exist!
2. Adjoint & Inversion Shortcuts
Fast Computation
2 × 2 Matrix Lightning Inverse Shortcut:
For A = [[a, b], [c, d]] with |A| = ad - bc ≠ 0:
1. Swap diagonal elements: a ↔ d.
2. Negate anti-diagonal elements: b → -b, c → -c.
A⁻¹ = (1 / |A|) · [[d, -b], [-c, a]]
3 × 3 Cofactor Matrix Definition:
• Minor Mij = determinant formed by deleting row i and column j.
• Cofactor Aij = (-1)ⁱ⁺ʲ Mij.
• Adjoint: adj(A) = [Aij]ᵀ (Transpose of cofactor matrix!).
Orthogonal Expansion Theorem:
• Same row expansion: ∑ aij Aij = |A|.
• Different row expansion: ∑ aij Akj = 0 (for i ≠ k).
Elements of any row multiplied by cofactors of another row always sum to ZERO!
Remember: adj(A) is the TRANSPOSE of cofactors. Missing the transpose is the #1 student error!
3. Cramer's Rule & Geometry
Applications
Cramer's Rule:
For non-singular coefficient determinant D = |A| ≠ 0:
x = Dx / D,   y = Dy / D,   z = Dz / D
where Dx replaces column 1 with constant vector B.
Area of Triangle via Determinant:
For vertices (x1, y1), (x2, y2), (x3, y3):
Δ = ½ | [x₁ y₁ 1; x₂ y₂ 1; x₃ y₃ 1] |
Always take absolute value since area must be positive!
Collinearity & Line Equation:
• Three points are collinear ⇔ Δ = 0.
• Equation of line through (x1, y1) and (x2, y2):
det([x y 1; x₁ y₁ 1; x₂ y₂ 1]) = 0.
When solving for unknown vertex coordinate k given area, remember Δ can be ±Area!
