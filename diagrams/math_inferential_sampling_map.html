FROM POPULATION TO VERDICT — THE INFERENCE PIPELINE

CUET UG · MATHEMATICS · INFERENTIAL STATISTICS

THE PIPELINE: POPULATION → SAMPLE → STATISTIC → DECISION

Population — everyone of interest. Constants: μ, σ = parameters (usually unknown)
→
Sample — the studied subset (n). Must be representative; drawn by SRS or systematic sampling
→
Statistic — computed from data: x̄, s (varies sample to sample) → estimates μ, σ
Sampling distribution of x̄: mean = μ, standard error = σ/√n; turns normal as n grows (Central Limit Theorem)
→
t-test: t = (x̄ − μ)/(s/√n), df = n − 1 → reject or keep H₀

Sampling designs (both give every unit a known chance)

Simple random (SRS): lottery or random-number table; with or without replacement — every unit equally likely.
Systematic: k = N/n; random start in 1…k, then every k-th unit — start 7, k = 10 gives 7, 17, 27…
Representative: mirrors the population's spread. Non-representative: convenience picks — friends, one street, one shift — biased conclusions.
Parameter vs statistic: μ, σ describe the population (fixed); x̄, s describe the sample (they wobble).

One-sample t-test — the 5-step recipe

State H₀ (status quo, "no change", the claim on trial) and H₁ (what doubt proposes)
Compute t = (x̄ − μ₀) / (s/√n) — sample mean minus claimed mean, scaled by the standard error
Degrees of freedom: df = n − 1 (one is spent estimating the mean)
Compare |t| with the table value at 5% (two-tail) for that df
Verdict: |t| beyond the table value → reject H₀ (significant); inside → keep H₀
Worked feel: n = 16, μ₀ = 50, x̄ = 48, s = 4 → t = −2/(4/4) = −2; df = 15, table 2.131 → |−2| < 2.131 → keep H₀.

TRAPS THE OPTIONS ARE BUILT AROUND

μ, σ are parameters; x̄, s are statistics — the Greek/Latin split is the whole question
SE = σ/√n — forgetting the √n scale blows every CLT number up
df = n − 1, not n — one degree is spent on the mean
Systematic start is random — picking the first unit arbitrarily breaks the design
Large |t| rejects H₀ — a small t is comfort for the status quo
H₀ carries the equality — H₁ is the strict inequality (≠, >, <)
