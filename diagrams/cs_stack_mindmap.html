STACK ADT

LIFO Architecture

1. Core ADT Principles

  • LIFO Rule: Last-In, First-Out access discipline. Insertion & removal at single endpoint ($Top$).
  • Stack Pointer: $Top = -1$ (Empty / Underflow state), $Top = Max - 1$ (Overflow state).
  • Underflow: Attempting to pop or peek from an empty stack (raises IndexError).
  • Overflow: Pushing onto a full fixed-capacity stack (unbounded in dynamic Python lists).

2. Primitive Operations & Mechanics

  • push(x): Inserts element $x$ at $Top$. Increments $Top$ pointer ($O(1)$ amortized).
  • pop(): Removes and returns top element. Decrements $Top$ ($O(1)$).
  • peek() / top(): Inspects top element without mutation ($O(1)$).
  • is_empty(): Checks if $Top == -1$ or len(s) == 0 ($O(1)$).
  • size(): Returns active element count ($O(1)$).

3. Implementation Models

  • Python List: Standard approach using append() & pop(). Amortized $O(1)$.
  • collections.deque: Doubly-linked blocks (64 items). Strict $O(1)$ without resizing spikes.
  • queue.LifoQueue: Thread-safe synchronized stack with locking primitives for concurrency.
  • Linked Stack: Pointer-linked nodes; dynamic allocation with zero resizing cost.

4. Expression Conversion & Evaluation

  • Notations: Infix ($A + B$), Prefix / Polish ($+ A B$), Postfix / RPN ($A B +$).
  • Infix to Postfix: Operator stack with precedence; operands bypass stack directly to output.
  • Postfix Evaluation: Operand stack; pop op2 then op1, compute op1 <op> op2.
  • Precedence: Parentheses > ** (Right-to-Left) > * / // % > + -.

5. The Seven Fatal CUET Traps

  • List Index 0 as Top: insert(0) & pop(0) take $O(N)$ time, ruining efficiency!
  • Operand Inversion: op1 - op2 vs op2 - op1 produces wrong signs and quotients.
  • Right-Associative Exponent: 2 ** 3 ** 2 = 512, NOT 64.
  • Unchecked Underflow: Always test if not stack: before popping!

6. Applications & Call Frames

  • Delimiter Balancing: Validating nested pairs (), [], {} with stack match.
  • Recursion & Call Frames: PVM allocates activation records on runtime call stack.
  • Recursion Limit: sys.getrecursionlimit() (default 1000); triggers RecursionError.
  • Backtracking: Browser History (Back/Forward), Undo/Redo buffers, DFS graph traversal.
