Structural Taxonomy of Data
Category Schema & Organization Formats & Examples
Structured Strict predefined tabular schema (rows & columns). Highly normalized. RDBMS tables, CSV files, SQL databases, Pandas DataFrames.
Semi-Structured Self-describing tags or key-value hierarchies. No rigid relational schema. JSON, XML, YAML, NoSQL documents, HTML trees.
Unstructured No conceptual schema or organizational structure. Binary or raw text. Images (JPEG/PNG), Audio (WAV/MP3), Video (MP4), PDFs, Free text blogs.
Storage & Query Paradigms:
  • Structured: Queried with declarative SQL; relational algebra.
  • Semi-Structured: Queried via XPath, JSONPath, MongoDB queries.
  • Unstructured: Indexed via full-text search, OCR, embeddings, or deep neural networks.

Missing Values & Imputation Matrix
Numerical Data Imputation Strategies • Symmetric Data: Impute with Mean.
• Skewed Data with Outliers: Impute with Median (robust against extremes).
• Time Series: Forward Fill (ffill) or Interpolation.
Categorical Data Imputation • Impute with Mode (most frequent value) or assign special sentinel "Missing" category.
Trap 1: Mean Imputation on Skewed Data Substituting missing values with the arithmetic mean in skewed distributions introduces artificial bias toward the heavy tail! Always use Median.
Trap 2: Deletion vs Imputation Threshold Dropping rows (`dropna`) is safe only if missingness is completely random and < 5%. Broad deletion distorts sample statistics.
