Module 1
DC & DR System
Direction Cosines (l, m, n)
l = cos α, m = cos β, n = cos γ
l² + m² + n² = 1
sin² α + sin² β + sin² γ = 2

Angles α, β, γ made with positive x, y, z axes.

Direction Ratios (a, b, c)
l/a = m/b = n/c = 1 / √(a² + b² + c²)
l = ± a / √(a² + b² + c²)

DRs are proportional to DCs. Line joining P(x1,y1,z1) & Q(x2,y2,z2) has DRs (x2-x1, y2-y1, z2-z1).

Proportionality: Any scalar multiple (ka, kb, kc) serves as DRs. DCs are strictly normalized to unit length!
Module 2
Equations of Lines
Point & Parallel Vector
Vector: r = a + λ b
Cartesian: (x-x1)/a = (y-y1)/b = (z-z1)/c

Passes through point a(x1, y1, z1) parallel to vector b = a·i + b·j + c·k.

Line Through Two Points
r = a + λ (b - a)
(x-x1)/(x2-x1) = (y-y1)/(y2-y1) = (z-z1)/(z2-z1)
Angle Between Two Lines
cos θ = |b1 · b2| / (|b1||b2|)
cos θ = |a1a2 + b1b2 + c1c2| / (√(Σa1²)√(Σa2²))

Perpendicular: a1a2 + b1b2 + c1c2 = 0.
Parallel: a1/a2 = b1/b2 = c1/c2.

Standard Form Trap: (1-x)/3 must be written as (x-1)/(-3). Coefficients of x, y, z in numerator must be +1!
Module 3
Shortest Distance (SD)
Skew Lines (Non-coplanar)
r = a1 + λ b1 & r = a2 + μ b2
d = |(b1 × b2) · (a2 - a1)| / |b1 × b2|

Lines that neither intersect nor are parallel in 3D space.

Cartesian Determinant SD
Num = det[x2-x1, y2-y1, z2-z1; a1,b1,c1; a2,b2,c2]
Denom = √[(b1c2-b2c1)² + (c1a2-c2a1)² + (a1b2-a2b1)²]
Parallel Lines
r = a1 + λ b & r = a2 + μ b
d = |b × (a2 - a1)| / |b|
Notice: For parallel lines, use cross product b × (a2-a1), NOT scalar triple product!
Module 4
Coplanarity & Intersect
Condition for Intersection
Shortest Distance d = 0
(b1 × b2) · (a2 - a1) = 0

Two non-parallel lines intersect if and only if their scalar triple product vanishes.

Cartesian Coplanarity Test
det | x2-x1 y2-y1 z2-z1 |
    |  a1     b1     c1   |
    |  a2     b2     c2   | = 0
Point of Intersection Method

1. Express general points P(λ) and Q(μ).
2. Equate x, y, z coordinates.
3. Solve for λ, μ from two equations.
4. Verify in third equation to confirm intersection.

If system for λ, μ has consistent solution satisfying all 3 coordinates, lines intersect at P(λ).
Direction Cosines satisfy l² + m² + n² = 1; Direction Ratios are any proportional numbers
Shortest distance between skew lines = |(b1 × b2) · (a2 - a1)| / |b1 × b2|
Lines intersect ⟺ Shortest distance = 0 ⟺ Determinant of (a2-a1), b1, b2 equals 0
