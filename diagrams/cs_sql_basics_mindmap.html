Core Architecture

🏛️ DDL: Schema Definition & Modification

  • CREATE TABLE: Defines relation name, attribute data types (CHAR, VARCHAR, INT, DATE) and constraints.
  • ALTER TABLE: Modifies schema dynamically via ADD (new column), MODIFY (data type/size), or DROP (removes attribute).
  • DROP TABLE: Permanently removes both the table schema and all records from database.
  • TRUNCATE TABLE: Flushes all rows instantaneously while preserving the empty table schema.
  • Auto-Commit Rule: All DDL statements implicitly auto-commit; cannot be reversed using ROLLBACK!

🛡️ Declarative Integrity Constraints

  • PRIMARY KEY: Enforces entity integrity: strictly UNIQUE and NOT NULL. Exactly one per table.
  • FOREIGN KEY: Enforces referential integrity pointing to parent PK. Supports CASCADE and SET NULL.
  • UNIQUE: Prohibits duplicate non-null entries; permits multiple NULL values.
  • NOT NULL: Forbids missing or absent values in the specified attribute.
  • CHECK: Validates custom domain predicates (e.g., CHECK (Salary > 0)).
  • DEFAULT: Supplies an automatic value when omitted during tuple insertion.

⚡ DML: Manipulation, Filtering & Sorting

  • INSERT INTO: Appends single or multi-row tuples into existing tables.
  • UPDATE ... SET: Modifies attribute values. Omitting WHERE updates all rows!
  • DELETE FROM: Purges matching rows. Omitting WHERE deletes all rows (rollback supported).
  • Predicate Operators: =, <>, <, >, <=, >= combined with AND, OR, NOT.
  • Special Operators: BETWEEN ... AND (inclusive), IN (discrete list), IS NULL.
  • Pattern Matching: LIKE '%' (0 or more chars) and LIKE '_' (exactly 1 char).
  • ORDER BY: Sorts output rows by one or more columns in ASC (default) or DESC.

📐 Built-in Scalar (Single-Row) Functions

  • String: LENGTH(), LOWER()/UPPER(), SUBSTR(s, pos, len) (1-indexed!), TRIM(), INSTR(s, sub), CONCAT().
  • Numeric: POWER(x, y), ROUND(x, d) (nearest), TRUNCATE(x, d) (chops digits), MOD(n, m).
  • Date/Time: CURDATE(), NOW(), DATE(), MONTH(), YEAR(), DAYNAME(), DAYOFMONTH().
  • Invariant: Single-row functions operate on individual tuples and return exactly one result per input row.
