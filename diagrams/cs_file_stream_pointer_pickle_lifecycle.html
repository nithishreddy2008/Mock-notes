▲ Current Pointer at Byte 4: f.tell() returns 4 | Next read reads 'o'
whence Reference Point Valid Modes Example Call
0 (default) Beginning of file (SEEK_SET) Text ('r') & Binary ('rb') f.seek(0) (Rewind to start)
1 Current position (SEEK_CUR) Binary ONLY (offset in bytes) f.seek(5, 1) (Forward 5 bytes)
2 End of file (SEEK_END) Binary ONLY (negative offset) f.seek(-10, 2) (Last 10 bytes)

⚠ CUET Trap: In Python 3 text mode ('r'), non-zero seek offsets with whence=1 or 2 raise UnsupportedOperation!

Binary Object Serialization (pickle) Lifecycle
STEP 1: DUMP

Serialization (Pickling)

pickle.dump(student_dict, file_handle_wb)
Python in-memory object → Byte stream written to disk

STEP 2: STORAGE

Raw Binary File on Disk

Compact, unencoded byte stream (not human-readable). Preserves complex nested data structures intact.

STEP 3: LOAD

Deserialization (Unpickling)

data = pickle.load(file_handle_rb)
Byte stream read from disk → Reconstructed in-memory object

STEP 4: EOF LOOP

Reading Sequential Objects until EOFError

while True:
  try: rec = pickle.load(f)
  except EOFError: break
