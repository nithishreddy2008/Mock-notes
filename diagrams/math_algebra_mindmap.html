1. Matrix Taxonomy
Structures
Matrix Definition:
Rectangular array of m × n elements arranged in m rows and n columns.
Special Types:
• Diagonal: aij = 0 for all i ≠ j
• Scalar: Diagonal entries equal k
• Identity (Iₙ): k = 1; AI = IA = A
Symmetric & Skew-Symmetric:
• Symmetric: Aᵀ = A
• Skew-symmetric: Aᵀ = -A
• aii = 0 on diagonal; odd order has |A| = 0.
Decomposition Theorem:
A = ½(A + Aᵀ) + ½(A - Aᵀ)
(Unique sum of symmetric and skew-symmetric parts).
Trace Tr(A) = sum of main diagonal entries.
2. Matrix Algebra
Operations
Matrix Multiplication (AB):
(m × n)(n × p) → (m × p).
• Non-commutative: AB ≠ BA
• Zero divisors: AB = O does NOT imply A = O or B = O!
Transpose Reversal Law:
(AB)ᵀ = Bᵀ Aᵀ
(ABC)ᵀ = Cᵀ Bᵀ Aᵀ
Matrix Inversion:
A square matrix is invertible ⇔ |A| ≠ 0 (non-singular).
A⁻¹ = adj(A) / |A|
Reversal Law: (AB)⁻¹ = B⁻¹ A⁻¹.
Orthogonal Matrix:
A Aᵀ = Aᵀ A = I ⇒ A⁻¹ = Aᵀ.
Cancellation rule: AB = AC ⇒ B = C only if |A| ≠ 0.
3. Determinant Rules
Multiplicative Laws
Core Multiplicative Laws:
• Product: |AB| = |A| · |B|
• Transpose: |Aᵀ| = |A|
• Inverse: |A⁻¹| = 1 / |A|
Scalar Factor (Order n):
|kA| = kⁿ |A|
(Each of the n rows pulls out factor k).
Adjoint Power Laws (Order n):
• |adj(A)| = |A|ⁿ⁻¹
• |adj(adj(A))| = |A|⁽ⁿ⁻¹⁾²
• adj(adj(A)) = |A|ⁿ⁻² A
Cofactor Expansion:
• Same row: ∑ aij Aij = |A|
• Other row: ∑ aij Akj = 0
For n=3: |adj(A)| = |A|²; |adj(adj(A))| = |A|⁴.
4. Linear Systems & Solvers
AX = B
Consistency Classification:
• |A| ≠ 0: Consistent & Unique solution X = A⁻¹ B.
• |A| = 0 & (adj A)B ≠ O: Inconsistent (No solution).
• |A| = 0 & (adj A)B = O: Infinitely many solutions.
Cramer's Rule:
x = Dₓ / D,   y = Dᵧ / D,   z = D_z / D
Geometric Applications:
• Triangle Area: Δ = ½ det([x y 1])
• Collinearity of 3 points ⇔ Δ = 0.
• Line equation through 2 points via det = 0.
Homogeneous AX = O: non-trivial solutions ⇔ |A| = 0.
