CUET UG MATHEMATICS

Matrix Basics

Order: m × n = m rows, n columns; element aij sits in row i, column j
Equality: same order + every entry equal — how you build "find x, y" questions
Types: row, column, square, zero O, diagonal, scalar, identity I, triangular
Symmetric: A′ = A · Skew: A′ = −A, so its diagonal is all 0

Matrix Operations

Add / subtract: same order only, element-wise
Scalar k: multiplies every entry
Product AB: rows of A dot columns of B; (m×n)(n×p) = m×p
Breaks algebra: AB ≠ BA; AB = O possible with A, B ≠ O; AB = AC ⇏ B = C

Transpose & Symmetry

Laws: (A′)′ = A, (A + B)′ = A′ + B′, (kA)′ = kA′, (AB)′ = B′A′
Split: A = ½(A + A′) + ½(A − A′) = symmetric + skew
Build tests: A + A′ is always symmetric, A − A′ always skew

Determinants

2×2: |A| = ad − bc · 3×3: expand along a row via cofactors
Properties: row swap flips sign; two equal rows ⇒ 0; |A′| = |A|; |AB| = |A||B|
|kA| = kⁿ|A| — the exponent is the matrix order
Area of triangle = ½|det|; zero determinant ⇔ collinear points

Adjoint & Inverse

adj A = transpose of the cofactor matrix
A(adj A) = |A| I — the identity that powers everything
A⁻¹ = adj A / |A| exists iff |A| ≠ 0 (non-singular), and is unique
2×2 shortcut: swap diagonal, negate the other two, divide by |A|

The Matrix Method (AX = B)

Write the system as AX = B with A = coefficients, X = variables, B = constants
|A| ≠ 0: unique solution X = A⁻¹B — solve in one multiplication
|A| = 0: either no solution (inconsistent) or infinitely many
Check: substitute the answer pair into the original equations

TOP TRAPS

|kA| is kⁿ|A|, never k|A|
(A + B)² ≠ A² + 2AB + B² because AB ≠ BA
Odd-order skew-symmetric ⇒ |A| = 0, so no inverse
