1. Relations Architecture
Binary Sets
Subset of Cartesian Product:
R ⊆ A × A. Empty ∅ and Universal A × A are trivial relations.
The Three Fundamental Axioms:
• Reflexive: (a, a) ∈ R ∀ a ∈ A
• Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R
• Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R
Equivalence Relation:
Reflexive + Symmetric + Transitive simultaneously. Partitions A into disjoint equivalence classes [a].
Combinatorial Counts (|A| = n):
• Total Relations: 2^(n²)
• Reflexive: 2^(n(n-1))
• Symmetric: 2^(n(n+1)/2)
Identity relation Δ = {(a,a)} is always an equivalence relation.
2. Function Mappings
Taxonomy
Function Definition:
Every element in domain A has exactly one unique image in codomain B.
Injective (One-One):
f(x1) = f(x2) ⇒ x1 = x2.
Horizontal line test: ≤ 1 cut. Calculus: strictly monotonic (f' > 0 or f' < 0).
Surjective (Onto):
Range(f) = Codomain(B). Every y has at least one pre-image x.
Bijective (One-One & Onto):
Necessary & sufficient condition for invertibility. |A| = |B| ⇒ n! bijections.
Function Counts (A → B):
• Total: nᵐ  |  Injections: ⁿPₘ
On finite sets of equal size, one-one ⇔ onto ⇔ bijection.
3. Composition & Inverses
Operations
Composition (f ∘ g)(x):
Defined as f(g(x)). Requires Range(g) ⊆ Domain(f).
• Associative: (f ∘ g) ∘ h = f ∘ (g ∘ h)
• Non-commutative: f ∘ g ≠ g ∘ f
Invertible Function f⁻¹:
f ∘ f-1 = IB and f-1 ∘ f = IA.
Exists if and only if f is bijective.
Reversal Law:
(f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹
Geometric Reflection:
The curve y = f-1(x) is the mirror image of y = f(x) about the line y = x.
f⁻¹(x) undoes the operation; it is NEVER equal to 1 / f(x).
4. Inverse Trig Engine
Principal Branches
The Six Principal Value Branches:
• sin⁻¹ x: [-1, 1] → [-π/2, π/2]
• cos⁻¹ x: [-1, 1] → [0, π]
• tan⁻¹ x: ℝ → (-π/2, π/2)
• cot⁻¹ x: ℝ → (0, π)
• sec⁻¹ x: |x| ≥ 1 → [0, π] \ {π/2}
• cosec⁻¹ x: |x| ≥ 1 → [-π/2, π/2] \ {0}
Negative Angle Rules:
• Odd: sin⁻¹(-x) = -sin⁻¹ x; tan⁻¹; cosec⁻¹
• π - Rule: cos⁻¹(-x) = π - cos⁻¹ x; cot⁻¹; sec⁻¹
Sum Identities:
• sin⁻¹ x + cos⁻¹ x = π/2
• tan⁻¹ x + cot⁻¹ x = π/2
Verify branch bounds: sin⁻¹(sin θ) = θ only inside [-π/2, π/2].
