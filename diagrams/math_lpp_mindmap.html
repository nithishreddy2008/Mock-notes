Complete 4-Quadrant Architecture
1. Anatomy & Mathematical Rigor Pillars
Decision Variables x, y ≥ 0
Physical non-negative quantities. Restricts search domain strictly to Quadrant 1.
Objective Function Z = ax + by
Linear function to be maximized or minimized. Must NOT contain non-linear terms.
Convex Feasible Region R ⊆ ℝ²
Common intersection of all constraint half-planes. Always forms a convex polygon/polyhedron.
Unit V Core
Linear Programming Optimization
Opt Z = ax + by
s.t. aᵢx + bᵢy ≤/≥ cᵢ
x ≥ 0, y ≥ 0
2-Dimensional Convex Optimization via Corner Point Evaluation and Half-Plane Slicing.
2. Fundamental Theorems & Solvers Theorems
Fundamental Theorem 1 Corner Invariant
Optimal solution of $Z$ always occurs at a corner point (vertex) of the feasible region.
Fundamental Theorem 2 Bounded Existence
If $R$ is bounded, both Maximum and Minimum values GUARANTEED to exist at vertices.
Corner Point Method Table Protocol
1. Solve line intersections $\implies$ 2. List all vertices $\implies$ 3. Compute $Z(x_k, y_k)$ $\implies$ 4. Pick $\max / \min$.
3. Feasible Region Classifications Geometry
Bounded Feasible Set Enclosed
Contained within a finite boundary. Both global maximum and minimum exist at corner points.
Unbounded Region Open Domain
Extends to infinity. Requires Open Half-Plane Test ($ax + by > M$ / $ax + by < m$).
Redundant Constraints Inactive
A constraint whose removal does not alter the feasible region (e.g., $x + y \le 10$ when $x + y \le 5$).
4. Special Cases & CUET Traps Traps
Multiple Optima (Infinite) Parallel Slope
Occurs when $Z$ is identical at two adjacent vertices $A$ and $B$. All points on segment AB are optimal!
Infeasible Problem R = ∅
No common shaded region exists among all constraints. No feasible solution.
Unbounded Solution Z → ∞
When open half-plane $ax + by > M$ intersects the feasible region, $Z$ has NO maximum value!
