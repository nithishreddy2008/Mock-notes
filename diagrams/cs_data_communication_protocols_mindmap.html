Master Synthesis Mindmap: Data Communication & Network Protocols

CUET UG Computer Science (Code 308) · Complete Architectural Blueprint of Transmission, Layers & Protocols

Comprehensive Mindmap
1
Data Transmission & Switching
• Transmission Modes: Simplex (unidirectional), Half-Duplex (alternating), Full-Duplex (simultaneous).
• Impairments: Attenuation (loss), Distortion (shape), Noise & Crosstalk (EMI).
• Switching Methods:
- Circuit: Dedicated physical path (PSTN).
- Message: Store-and-forward whole message.
- Packet: Independent packets (Datagram / Virtual Circuit). Internet foundation.
2
OSI & TCP/IP Layered Models
• OSI 7 Layers: Application, Presentation, Session, Transport, Network, Data Link, Physical.
• TCP/IP 4 Layers: Application (5-7), Transport (4), Internet (3), Network Access (1-2).
• PDUs: Data → Segment (L4) → Packet (L3) → Frame (L2) → Bits (L1).
• Encapsulation: Headers added going down; stripped going up (decapsulation).
3
Transport Layer (TCP vs UDP)
• TCP: Connection-oriented, 3-way handshake (SYN, SYN-ACK, ACK). Reliable, ordered delivery, sliding window flow control.
• UDP: Connectionless, unreliable, best-effort. Zero handshake, minimal overhead. Ideal for VoIP, DNS, live video streaming.
• Addressing: 16-bit Port Numbers (0–65535). Well-known: 0–1023.
4
Network Layer & Addressing
• IPv4 Addressing: 32 bits (4 octets). Classes A (/8), B (/16), C (/24), D (Multicast), E (Experimental). Loopback: 127.0.0.1.
• IPv6 Addressing: 128 bits (8 colon-hex groups). Massive space.
• Resolution Protocols:
- ARP: Maps known IP → unknown physical MAC.
- ICMP: Error reporting & diagnostics (Ping, Traceroute).
5
Application Web & File Protocols
• HTTP (Port 80): Stateless plaintext request/response.
• HTTPS (Port 443): Encrypted HTTP over TLS/SSL certificates.
• FTP: Port 21 (Commands/Control) & Port 20 (Data transfer).
• DNS (Port 53): Hierarchical hostname-to-IP resolution. Uses UDP for queries, TCP for zone sync.
6
Email, Remote Access & Voice
• Email Protocols:
- SMTP (25/587): Pushes outgoing mail.
- POP3 (110): Downloads mail & deletes from server.
- IMAP (143): Syncs mail across multiple devices.
• Remote Access: Telnet (23, plaintext) vs SSH (22, encrypted).
• VoIP: Voice over IP using SIP (signaling) & RTP (voice media).
