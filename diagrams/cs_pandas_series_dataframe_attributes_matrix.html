Pandas Data Structures: Series vs DataFrame Comparative Matrix

Pandas 2.x API Standards
Property / Attribute Pandas Series (1D Structure) Pandas DataFrame (2D Structure) CUET High-Yield Exam Trap & Behavior
Dimensionality 1-Dimensional (1D) 2-Dimensional (2D Tabular) Series has 1 axis (Index); DataFrame has 2 axes (Index = rows, Columns = cols)
Data Homogeneity Homogeneous (Single dtype) Heterogeneous (Columns can have different dtypes) If mixed types passed to Series, upcasts to object or float64
Mutability Value Mutable; Size Immutable Value Mutable; Size Mutable Cannot insert elements into Series without creating a new object
.shape Tuple: (n,) (Single integer) Tuple: (num_rows, num_cols) Series shape has length 1: (5,), NOT (5, 1)!
.ndim Integer: 1 Integer: 2 Strictly returns integer dimensions: 1 for Series, 2 for DataFrame
.size Integer: n (Total elements) Integer: num_rows × num_cols DataFrame size is the product of row count and column count
.axes List of 1 item: [Index] List of 2 items: [Index, Columns] df.axes[0] is row index; df.axes[1] is column index
.T (Transpose) Returns self (no-op; 1D array) Swaps rows and columns ((r, c) → (c, r)) Transposing Series does nothing; transposing DataFrame flips axes
Positional Slicing s[0:3] Excludes stop index df.iloc[0:3] Excludes stop index Standard Python half-open slice: includes 0, 1, 2; excludes 3
Label-based Slicing s['a':'c'] INCLUDES stop label! df.loc['a':'c'] INCLUDES stop label! FATAL TRAP: Label slicing is closed; includes label 'c'!
Core Invariant: Positional slice [0:n] stops at n-1 · Label slice ['a':'c'] stops at 'c' (inclusive)
