अच् सवर्णदीर्घः अकः सवर्णे दीर्घः (६.१.१०१) अक् (अ, इ, उ, ऋ, ऌ) + सवर्ण अक् = पूर्व-परयोः दीर्घ एकादेशः (आ, ई, ऊ, ॠ) दैत्य + अरिः = दैत्यारिः, श्री + ईशः = श्रीशः, पितृ + ऋणम् = पितॄणम्
अच् गुण-सन्धिः आद्गुणः (६.१.८७) / अदेङ् गुणः अ/आ + (इ/ई, उ/ऊ, ऋ/ॠ, ऌ) = पूर्व-परयोः गुण एकादेशः (ए, ओ, अर्, अल्) नर + ईशः = नरेशः, सूर्य + उदयः = सूर्योदयः, महा + ऋषिः = महर्षिः
अच् वृद्धि-सन्धिः वृद्धिरेचि (६.१.८८) / वृद्धिरादैच् अ/आ + एच (ए, ऐ, ओ, औ) = पूर्व-परयोः वृद्धि एकादेशः (ऐ, औ) एक + एकम् = एकैकम्, जल + ओघः = जलौघः, देव + ऐश्वर्यम् = देवैश्वर्यम्
अच् यण्-सन्धिः इको यणचि (६.१.७७) इक् (इ/ई, उ/ऊ, ऋ/ॠ, ऌ) + असवर्ण अच् = इक् स्थाने यण् (य्, व्, र्, ल्) आदेशः प्रति + एकम् = प्रत्येकम्, मधु + अरिः = मध्वरिः, पितृ + आदेशः = पित्रादेशः
अच् अयादि / पूर्वरूप एचोऽयवायावः / एङः पदान्तादति एच + अच् = अय्, अव्, आय्, आव् / पदान्ते ए/ओ + ह्रस्व अ = पूर्वरूपम् (ऽ) ने + अनम् = नयनम्, पौ + अकः = पावकः; हरे + अव = हरेऽव
हल् श्चुत्व / ष्टुत्व स्तोः श्चुना श्चुः / ष्टुना ष्टुः स्/तवर्गस्य श्/चवर्गेण योगे श्/चवर्गः; ष्/टवर्गेण योगे ष्/टवर्ग आदेशः सत् + चित् = सच्चित्, रामस् + शेते = रामश्शेते; तत् + टीका = तट्टीका
हल् जश्त्व / चर्त्व झलां जशोऽन्ते (८.२.३९) / खरि च पदान्ते झल् स्थाने जश् (३य वर्णः: ग्, ज्, ड्, द्, ब्); खर् परे चर् (१म वर्णः) वाक् + ईशः = वागीशः, जगत् + ईशः = जगदीशः; सद् + कारः = सत्कारः
विसर्ग उत्वम् / रुत्वम् अतो रोरप्लुतादप्लुते / हशि च ह्रस्व 'अ' + विसर्ग + ह्रस्व 'अ'/'हश्' (३,४,५, यवरलह) = विसर्गस्य 'उ', गुणश्च (ओ) शिवः + अर्च्यः = शिवोऽर्च्यः, रामः + गच्छति = रामो गच्छति
