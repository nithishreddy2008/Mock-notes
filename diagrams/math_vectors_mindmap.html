VECTORS & 3D GEOMETRY
CUET UG MATHEMATICS

Vector Basics

Magnitude + direction; scalars carry only size
Types: zero, unit (|a| = 1), equal, parallel/collinear
Components: a = a₁î + a₂ĵ + a₃k̂; |a| = √(a₁²+a₂²+a₃²)
Section formula: (m b + n a)/(m+n) internally; midpoint = (a+b)/2

Direction Cosines & Ratios

l, m, n = cosines with x, y, z axes
l² + m² + n² = 1 — the identity that polices them
Ratios a, b, c only need proportionality
Convert: l = a/√(a²+b²+c²) etc.

Dot & Cross (the workhorses)

a·b = |a||b|cos θ — number; 0 ⇔ perpendicular
|a×b| = |a||b|sin θ — vector ⊥ both; 0 ⇔ parallel
Areas: parallelogram |a×b|, triangle ½|a×b|
Projection: (a·b)/|b|

Scalar Triple Product

[a b c] = a·(b×c) = 3×3 determinant
Volume of parallelepiped = |[a b c]|
Zero ⇔ coplanar — the flatness verdict
Tetrahedron: volume (1/6)|[a b c]|

Lines in 3D

r = a + λ b and the cartesian twin with l, m, n
Skew: not parallel, never meeting; SD via b₁×b₂
Parallel SD: |(a₂−a₁)×b|/|b|
Angle: cos θ between direction vectors

Planes & Distances

r·n = d / lx + my + nz = d — normal is the ID card
Plane ⊥ n through a: (r − a)·n = 0
Point-plane distance: |ax₁+by₁+cz₁−d|/√(a²+b²+c²)
Line-plane angle uses sin θ = |b·n|/(|b||n|)

TOP TRAPS

Dot-zero vs cross-zero — perpendicular vs parallel verdicts
sin vs cos — line-plane angle is a sine, plane-plane a cosine
l²+m²+n² = 1 — ratios never satisfy it, cosines always
