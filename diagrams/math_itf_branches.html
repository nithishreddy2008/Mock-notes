The Six Master Principal Value Branches
Standard Branches
Function Domain (x) Principal Value Range (y) Key Constraint / Notes
sin⁻¹ x [-1, 1] [-π/2, π/2] Closed interval; strictly increasing; passes origin
cos⁻¹ x [-1, 1] [0, π] Closed interval; strictly decreasing; always ≥ 0
tan⁻¹ x (-∞, ∞) = ℝ (-π/2, π/2) Open interval; horizontal asymptotes at ±π/2
cot⁻¹ x (-∞, ∞) = ℝ (0, π) Open interval; strictly decreasing; range is strictly positive
sec⁻¹ x (-∞, -1] ∪ [1, ∞) [0, π] \ {π/2} Excludes π/2 (cos π/2 = 0); |x| ≥ 1
cosec⁻¹ x (-∞, -1] ∪ [1, ∞) [-π/2, π/2] \ {0} Excludes 0 (sin 0 = 0); |x| ≥ 1
Complementary Co-Function Sum Identities: π/2 Sums
• sin⁻¹ x + cos⁻¹ x = π/2   (for all x ∈ [-1, 1])
• tan⁻¹ x + cot⁻¹ x = π/2   (for all x ∈ ℝ)
• sec⁻¹ x + cosec⁻¹ x = π/2   (for all |x| ≥ 1)
Critical CUET Tip: sin⁻¹(sin θ) = θ ONLY when θ ∈ [-π/2, π/2]! If θ is outside, reduce using periodicity/quadrants.
Negative-Angle Rules & Addition Engine
High-Yield Algebra
Group 1: Odd Symmetry (Minus Sign Factorizes Out) Range around 0
• sin⁻¹(-x) = -sin⁻¹ x   (for x ∈ [-1, 1])
• tan⁻¹(-x) = -tan⁻¹ x   (for x ∈ ℝ)
• cosec⁻¹(-x) = -cosec⁻¹ x   (for |x| ≥ 1)
Group 2: The π - Rule (Non-Negative Range Branches) Range [0, π]
• cos⁻¹(-x) = π - cos⁻¹ x   (for x ∈ [-1, 1])
• cot⁻¹(-x) = π - cot⁻¹ x   (for x ∈ ℝ)
• sec⁻¹(-x) = π - sec⁻¹ x   (for |x| ≥ 1)
Addition & Subtraction of tan⁻¹: Key Problem Solver
• tan⁻¹ x + tan⁻¹ y = tan⁻¹((x + y) / (1 - xy))   (if xy < 1)
• tan⁻¹ x - tan⁻¹ y = tan⁻¹((x - y) / (1 + xy))   (if xy > -1)
2 tan⁻¹ x = sin⁻¹(2x / (1 + x²)) = cos⁻¹((1 - x²) / (1 + x²)) = tan⁻¹(2x / (1 - x²))
(Triple conversion bridge connecting tangent to sine, cosine, and tangent double angles)
Always verify xy < 1 before applying the addition formula for tan⁻¹ x + tan⁻¹ y!
