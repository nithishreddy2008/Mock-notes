CUET UG · MATHEMATICS · RELATIONS & FUNCTIONS

Relation checklists (run all three)

Reflexive: (a, a) ∈ R for EVERY a in A — one missing pair breaks it
Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R — every arrow needs its mirror
Transitive: (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R — check every chain
Equivalence: all three at once — the identity relation always qualifies
Worked feel: R = {(1,1),(2,2),(3,3),(1,2),(2,1)} on {1,2,3} → all three ✓ = equivalence

Function classifications

One-one (injective): different inputs → different outputs; no repeated images
Onto (surjective): every codomain element gets used; range = codomain
Bijective: both — the only kind that owns an inverse
Composite: f∘g means g first, then f — read inside-out, never swap casually
Inverse: undo the machine — f⁻¹(f(x)) = x; 1/f is NOT f⁻¹

INVERSE TRIGONOMETRIC — DOMAIN, RANGE, PRINCIPAL BRANCH (memorise cold)

sin⁻¹x
Domain [−1, 1]
Range [−π/2, π/2]
Odd function; sin⁻¹x + cos⁻¹x = π/2
cos⁻¹x
Domain [−1, 1]
Range [0, π]
Not odd; mirrors sin⁻¹ by the sum rule above
tan⁻¹x
Domain ℝ
Range (−π/2, π/2)
Open bounds — ±π/2 never attained; tan⁻¹x + cot⁻¹x = π/2
cot⁻¹x
Domain ℝ
Range (0, π)
Pair-partner of tan⁻¹ via the sum rule
sec⁻¹x
Domain ℝ − (−1, 1)
Range [0, π] − {π/2}
|x| ≥ 1 only; π/2 is skipped
cosec⁻¹x
Domain ℝ − (−1, 1)
Range [−π/2, π/2] − {0}
|x| ≥ 1 only; 0 is skipped

TRAPS THE OPTIONS ARE BUILT AROUND

Reflexive needs EVERY (a,a) — a single absent pair sinks it
Transitive chains: one broken (a,c) link disqualifies the relation
f⁻¹ ≠ 1/f — the inverse is an undo, not a reciprocal
f∘g ≠ g∘f — composition order is content, not style
sin not one-one on ℝ — that is WHY principal branches exist
Range brackets matter: tan⁻¹ never reaches ±π/2; sec⁻¹ skips π/2
