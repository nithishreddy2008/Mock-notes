Exception & File Handling

Python Robust I/O Framework
1. Exception Handling Architecture TRY-EXCEPT
  • Syntax Error vs Exception: Parsing stage vs runtime occurrence.
  • Hierarchy: BaseException → Exception → Built-in classes.
  • try-except-else-finally: else runs on 0 errors; finally runs always.
  • raise statement: Explicitly triggers built-in or custom errors.
  • Custom Exceptions: Inherit from Exception class.
2. Text File Processing OPEN & READ
  • Context Manager: with open(...) as f: auto-closes file.
  • read([n]): Reads $n$ characters or entire file into single str.
  • readline(): Reads single line including newline ' '.
  • readlines(): Reads all lines into a Python list of strings.
  • write() & writelines(): String output (no automatic ' ').
3. Stream Pointer Navigation SEEK & TELL
  • tell(): Returns current byte offset of file pointer.
  • seek(offset, whence): Relocates stream position.
  • whence=0: Absolute offset from file beginning (SEEK_SET).
  • whence=1: Relative offset from current pos (Binary only).
  • whence=2: Relative offset from EOF (Binary only).
4. Binary Files & Pickle DUMP & LOAD
  • Binary Modes: 'rb', 'wb', 'ab' (raw byte streams, no encoding).
  • pickle.dump(obj, f): Serializes Python object into binary file.
  • pickle.load(f): Deserializes byte stream back into Python object.
  • EOF Detection: Loop terminates via except EOFError: break.
  • Preservation: Dictionaries, lists, and tuples keep exact types.
