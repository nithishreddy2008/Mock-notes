चित्र 1: संधि एवं समास — संरचनात्मक नियम, भेद एवं परीक्षा-सूत्र मैट्रिक्स

CUET UG हिंदी में सर्वाधिक पूछे जाने वाले संधि-विच्छेद एवं समास-विग्रह के अनिवार्य नियम

व्याकरण मैट्रिक्स · CUET UG 102
व्याकरणिक कोटि मूल परिभाषा व पहचान परिवर्तन सूत्र / बीजगणितीय नियम CUET उच्च-प्राथमिकता उदाहरण
स्वर संधि (5 भेद) दो स्वरों के मेल से होने वाला ध्वनि विकार। • दीर्घ: अ/आ + अ/आ = आ, इ/ई + इ/ई = ई
• गुण: अ/आ + इ/ई = ए, + उ/ऊ = ओ, + ऋ = अर्
• वृद्धि: अ/आ + ए/ऐ = ऐ, + ओ/औ = औ
• यण: इ/ई + भिन्न = य्, उ/ऊ + भिन्न = व्, ऋ = र्
• अयादि: ए = अय्, ऐ = आय्, ओ = अव्, औ = आव् 		• विद्या + आलय = विद्यालय (दीर्घ)
• देव + इंद्र = देवेंद्र, महा + ऋषि = महर्षि (गुण)
• मत + ऐक्य = मतैक्य, वन + औषधि = वनौषधि (वृद्धि)
• यदि + अपि = यद्यपि, अनु + अय = अन्वय (यण)
• ने + अन = नयन, पौ + अक = पावक (अयादि)
व्यंजन संधि व्यंजन का व्यंजन या स्वर से मेल होने पर विकार। • वर्ग के 1ले वर्ण का 3रे में परिवर्तन: क्/त्/प् + घोष = ग्/द्/ब्
• वर्ग के 1ले वर्ण का 5वें में परिवर्तन: क्/त् + न्/म् = ङ्/न्
• त्-संबंधी नियम: त् + च् = च्च, त् + ज् = ज्ज, त् + ल् = ल्ल 		• दिक् + अंत = दिगंत, वाक् + ईश = वागीश
• उत् + नति = उन्नति, जगत् + नाथ = जगन्नाथ
• उत् + चारण = उच्चारण, उत् + ज्वल = उज्ज्वल
• तत् + लीन = तल्लीन, सत् + जन = सज्जन
विसर्ग संधि विसर्ग (:) के साथ स्वर या व्यंजन के मेल पर विकार। • विसर्ग का 'ओ': अः + घोष व्यंजन = ओ
• विसर्ग का 'र्': अ/आ से भिन्न स्वर + विसर्ग + घोष = र्
• विसर्ग का 'श्/ष्/स्': विसर्ग + च्/छ् = श्, + ट्/ठ् = ष्, + त्/थ् = स् 		• मनः + योग = मनोयोग, तपः + वन = तपोवन
• निः + धन = निर्धन, दुः + बल = दुर्बल
• निः + चल = निश्चल, धनुः + टंकार = धनुष्टंकार
• नमः + ते = नमस्ते, निः + संतान = निस्संतान
समास (6 भेद) दो या अधिक पदों का विभक्ति-लोप द्वारा संक्षिप्त रूप। • अव्ययीभाव: पूर्वपद प्रधान व अव्यय (यथा-, प्रति-, आ-)
• तत्पुरुष: उत्तरपद प्रधान, कारक विभक्तियों का लोप
• कर्मधारय: विशेषण-विशेष्य या उपमान-उपमेय संबंध
• द्विगु: पूर्वपद संख्यावाचक, समूह/समाहार का बोध
• द्वंद्व: दोनों पद प्रधान, योजक 'और', 'या' का लोप
• बहुव्रीहि: दोनों पद अप्रधान, तीसरा सांकेतिक अर्थ प्रधान 		• आजन्म (जन्म भर), यथाशक्ति (शक्ति के अनुसार)
• राजपुत्र (राजा का पुत्र), रोगमुक्त (रोग से मुक्त)
• चरणकमल (कमल रूपी चरण), नीलगगन
• पंचवटी (पाँच वटों का समाहार), चौराहा
• माता-पिता (माता और पिता), सुख-दुख
• चक्रपाणि (विष्णु), पीतांबर (श्रीकृष्ण), दशानन (रावण)
