THE MATRIX & DETERMINANT TOOLKIT

CUET UG · MATHEMATICS · ALGEBRA

Know your matrices (order m × n, element aij)

Row
1 × n — one row
Column
n × 1 — one column
Square
n × n — rows = columns; only these have determinants
Zero O
every entry 0; add/subtract identity element
Diagonal
non-zero only on the main diagonal
Scalar / Identity
diagonal with equal entries k; k = 1 gives I — the multiplication identity
Symmetric
A′ = A — mirror across the main diagonal
Skew-symmetric
A′ = −A; diagonal must be 0; odd order ⇒ |A| = 0
Triangular
upper: zeros below diagonal; lower: zeros above

Operations — what obeys rules, what breaks them

Add / subtract
Same order only; add element-wise. A + O = A, A + (−A) = O.
Scalar multiply
k hits every entry. k(A + B) = kA + kB.
Multiply A·B
Row × column dot products; shapes must chain: (m×n)(n×p) = m×p. Not commutative: AB ≠ BA in general. AB = O is possible with A ≠ O, B ≠ O (e.g. A=[1 1; 2 2], B=[1 1; −1 −1]). No cancelling: AB = AC ⇏ B = C.
Transpose A′
Rows become columns. (A′)′ = A, (A + B)′ = A′ + B′, (kA)′ = kA′, (AB)′ = B′A′ (order flips!).
Split any square A
A = P + Q with P = ½(A + A′) symmetric, Q = ½(A − A′) skew-symmetric.

The determinant → inverse → solve pipeline

1
Determinant |A| — 2×2: ad − bc. 3×3: expand along a row with cofactors (−1)ⁱ⁺ʲ Mij.
▼
2
Adjoint — replace entries by cofactors, then transpose. A·adj A = |A|·I and |adj A| = |A|ⁿ⁻¹.
▼
3
Inverse — A⁻¹ = adj A / |A|, exists only when |A| ≠ 0 (non-singular). Unique.
▼
4
Solve AX = B — X = A⁻¹B, a unique solution. If |A| = 0: no solution (inconsistent) or infinitely many.

TRAPS THE OPTIONS ARE BUILT AROUND

|kA| = kⁿ|A|, not k|A| — the power is the order
(A + B)² ≠ A² + 2AB + B² — expand honestly: A² + AB + BA + B²
AB = O ⇏ A = O or B = O — zero divisors exist
AB = AC ⇏ B = C — no cancellation law for matrices
Symmetric + skew test: diagonal of a skew matrix must be 0
|A′| = |A| and |AB| = |A||B| — free marks, often forgotten
