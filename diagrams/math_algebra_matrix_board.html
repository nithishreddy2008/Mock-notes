1. Matrix Taxonomy & Special Types
Structures
Square Matrix (n × n): Number of rows equals number of columns. Only square matrices possess determinants, traces, and inverses.
Diagonal Matrix: aij = 0 for all i ≠ j. Non-zero entries exist exclusively on the main diagonal.
Scalar & Identity Matrix: Diagonal entries equal constant k. If k = 1, it forms the Identity matrix In (multiplicative identity: AI = IA = A).
Symmetric Matrix: AT = A (i.e., aij = aji). Mirror symmetry across main diagonal. Any square matrix A can be uniquely written as:
A = ½(A + Aᵀ) + ½(A - Aᵀ)
Skew-Symmetric Matrix: AT = -A (i.e., aij = -aji).
• Diagonal entries must be zero (aii = 0).
• Key Theorem: For an odd order skew-symmetric matrix, det(A) = 0 identically!
Trace of square matrix Tr(A) = ∑ aii (sum of principal diagonal elements).
2. Matrix Operations & Inversion
Algebra
Addition & Scalar Multiplication:
• Addition requires identical dimensions (m × n). Commutative & associative.
• Scalar k multiplies every single element: (kA)ij = k aij.
Matrix Multiplication (AB):
Inner dimensions must match: (m × n)(n × p) → (m × p).
• Non-Commutative: In general, AB ≠ BA.
• Zero Divisors: AB = O does not imply A = O or B = O. Two non-zero matrices can multiply to yield the zero matrix!
Transpose Reversal Law:
(AB)ᵀ = Bᵀ Aᵀ and (ABC)ᵀ = Cᵀ Bᵀ Aᵀ.
Matrix Inversion Formula:
A square matrix A is invertible if and only if det(A) ≠ 0 (non-singular):
A⁻¹ = adj(A) / det(A)  |  (AB)⁻¹ = B⁻¹ A⁻¹
Cancellation Trap: AB = AC does NOT imply B = C unless A is non-singular!
3. Determinant Multiplicative Laws
High-Yield Rules
Product Rule:
|AB| = |A| · |B| (Holds for square matrices of equal order).
Scalar Scaling Law (Order n):
|kA| = kⁿ |A|
Each of the n rows pulls out a factor of k. (Very common CUET trap!).
Transpose & Inverse Determinants:
• |Aᵀ| = |A| (Rows & columns interchanged leaves det invariant).
• |A⁻¹| = 1 / |A| = (|A|)⁻¹.
Adjoint Determinant Power Laws (Order n):
• |adj(A)| = |A|ⁿ⁻¹
• |adj(adj(A))| = |A|⁽ⁿ⁻¹⁾²
• adj(adj(A)) = |A|ⁿ⁻² A
Fundamental Adjoint Identity:
A · adj(A) = adj(A) · A = |A| Iₙ
For 3×3 matrix with |A| = 4: |2A| = 2³(4) = 32; |adj(A)| = 4² = 16!
