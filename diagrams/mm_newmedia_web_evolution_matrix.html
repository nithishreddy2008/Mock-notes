Comparative Paradigm: Web 1.0 vs. Web 2.0 vs. Web 3.0 vs. Traditional Media

Technological, Participatory, and Governance Architecture for CUET UG Mass Media Studies · Unit 8

FIGURE 1 · CONCEPT MATRIX
Core Dimension Traditional Mass Media Web 1.0 (Static Web) Web 2.0 (Social / Read-Write) Web 3.0 (Semantic / Spatial)
User Agency & Role PASSIVE AUDIENCE
One-way linear consumption; audience cannot reply or co-create broadcasts.		 READ-ONLY CONSUMER
Browsing static hyperlinked portals (AltaVista, early Yahoo, personal HTML homepages).		 PROSUMER / CREATOR
Read-Write participatory culture; users co-create, upload, remix, comment & share.		 OWNER / DECENTRALIZED
Read-Write-Own; sovereign digital identity, semantic interoperability & smart contracts.
Content Architecture ANALOG BROADCAST
Fixed print column inches, scheduled TV programming slots, rigid physical editions.		 STATIC HYPERTEXT
Server-hosted static HTML documents; webmaster updates files manually via FTP.		 DYNAMIC USER-GENERATED
Folksonomies, wikis, social feeds, AJAX, cloud databases, live streaming video.		 SEMANTIC & SPATIAL
Ontology standards (RDF, OWL), machine-readable linked metadata, spatial 3D/AI models.
Gatekeeping & Curation INSTITUTIONAL EDITORS
Chief editors, censor boards, and broadcasting executives filter all content.		 WEBMASTER CURATION
Webmasters curate directory categories and external hyperlink directories.		 ALGORITHMIC CURATION
Engagement algorithms, recommendation AI, viral shares, peer crowdsourcing.		 DECENTRALIZED PROTOCOLS
Community consensus mechanisms, cryptographic trust, transparent open algorithms.
Data Ownership & Capital MEDIA CONGLOMERATE
Corporate owners own printing presses, broadcast licenses, and copyright archives.		 DOMAIN HOSTING
Proprietary web hosts and server owners control all access and hosted content.		 SURVEILLANCE CAPITALISM
Centralized tech monopolies (Big Tech) harvest behavioral user data for targeted ads.		 USER DATA SOVEREIGNTY
Decentralized ledgers, cryptographic self-sovereign identity, portable user assets.
Interactivity & Social Flow ONE-TO-MANY (MONOLOGUE)
Central transmitter to dispersed, atomized mass audience without feedback channels.		 ONE-TO-MANY (DIGITAL)
Webmaster publishes information; basic email contact forms with delayed response.		 MANY-TO-MANY (NETWORK)
Ubiquitous viral sharing, social tagging, hashtag movements, synchronous messaging.		 PEER-TO-PEER (AUTONOMOUS)
Autonomous agents, machine-to-machine exchange, contextual ubiquitous computing.
