UNIT VI · COMPUTERISED ACCOUNTING
The Five Structural Components of an AIS System Framework
An Accounting Information System (AIS) transforms financial transaction data into structured financial intelligence through five interdependent elements:
Hardware
Computers, servers, input scanners, printers.
Software
OS, RDBMS engine, accounting application.
People
Data entry clerks, accountants, system admin.
Procedures
Operating manuals, internal control rules.
Data
Vouchers, ledgers, transaction records.
Single-Point Data Entry: In a CAS, transaction data is keyed in only ONCE via the voucher; ledgers, trial balance, and balance sheet update automatically!

Manual Accounting vs Computerised Accounting Operational Contrast
• Recording: Manual requires writing journal entries in bound books; CAS records digital vouchers into relational tables.
• Posting & Ledger Closure: Manual requires tedious hand-posting and balancing; CAS performs instant, real-time posting without human error.
• Trial Balance Generation: Manual requires extracting balances and manual totaling; CAS generates unadjusted and adjusted Trial Balances instantly.
• Internal Audit Trail: Manual uses physical signatures; CAS uses digital user timestamps, logs, and cryptographic hashes.
GIGO Principle: "Garbage In, Garbage Out" — if incorrect voucher data is entered, CAS will automatically generate erroneous balance sheets!
Account Codification Structures in CAS Chart of Accounts
Sequential Code
Consecutive numbers assigned in strict order: 001, 002, 003. Simple, but cannot add new items in between.
Block Code
Ranges reserved for account families: 1000–1999 (Assets), 2000–2999 (Liabilities), 3000–3999 (Revenue).
Mnemonic Code
Letters or abbreviations aiding human recall: DEL (Delhi Branch), HQ (Headquarters), CASH (Cash Account).
Hierarchical (Decimal) Code
Multi-tier nested classification: 1000 (Current Assets) -> 1100 (Cash) -> 1110 (Petty Cash). Standard in modern ERPs.
CUET Rule: Block codes and Hierarchical codes are the most widely used methods in modern corporate Chart of Accounts.
