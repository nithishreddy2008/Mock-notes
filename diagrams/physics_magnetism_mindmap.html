1. Biot-Savart Law & Circular Coil

Current Elements
  • Biot-Savart Formula: dB = (μ₀/4π)(I dl × r̂)/r²
  • Center of Circular Coil: B_center = (μ₀ N I) / (2R)
  • Axial Field: B_ax = [μ₀ N I R²] / [2(R² + x²)^(3/2)]
  • Far Axial Dipole: For x ≫ R, mimics dipole B = (μ₀/4π)(2M / x³)
  • Right-Hand Palm Rule: Fingers along current, thumb gives magnetic field.

2. Ampere's Law & Conductor Forces

Circuital Laws
  • Ampere's Circuital Law: ∮ B · dl = μ₀ · I_enc
  • Long Straight Wire: B = (μ₀ I) / (2π r)
  • Solenoid: Core field B = μ₀ n I; End field B_end = ½ μ₀ n I
  • Force on Current: F = I (L × B) = I L B sin θ
  • Parallel Wires: Force per length f = (μ₀ I₁ I₂) / (2π d). Like attract, opposite repel (1 A = 2×10⁻⁷ N/m).

3. Lorentz Force & Particle Motion

Particle Dynamics
  • Lorentz Equation: F = q (E + v × B); magnetic force F_m = q (v × B)
  • Zero Work Invariant: F_m ⊥ v ⟹ P = 0; KE remains strictly constant.
  • Circular Orbit (v ⊥ B): Radius r = (m v) / (q B); Period T = (2π m) / (q B)
  • Helical Path (angle θ): Pitch p = v_∥ · T = (2π m v cos θ) / (q B)
  • Velocity Selector: Crossed fields select v = E / B undeviated.

4. Magnetic Dipole & Bar Magnet

Dipole Physics
  • Current Loop Dipole: M = N I A (vector normal to loop plane).
  • Bohr Magneton: Minimum atomic moment μ_B = (e ℏ) / (2 m_e) ≈ 9.27×10⁻²⁴ A·m²
  • Torque on Dipole: τ = M × B = M B sin θ (stable at 0°, unstable at 180°).
  • Potential Energy: U = - M · B = - M B cos θ; Work W = M B(cos θ₁ - cos θ₂)
  • Gauss's Law for Magnetism: ∮ B · dA = 0 (No magnetic monopoles).

5. Moving Coil Galvanometer & Meters

Instrument Design
  • Radial Magnetic Field: Concave poles + soft iron core ensure θ = 90°; τ = N I A B.
  • Linear Deflection: Restoring torque C θ = N I A B ⟹ θ = (N A B / C) · I
  • Current Sensitivity: I_s = θ / I = (N A B) / C [div/A]
  • Ammeter Conversion: Low parallel shunt S = (I_g G) / (I - I_g); R_A ≈ 0
  • Voltmeter Conversion: High series resistor R_s = (V / I_g) - G; R_V ≈ ∞

6. Magnetic Properties & Materials

Material Physics
  • Permeability & Susceptibility: B = μ₀ (H + M); μ_r = 1 + χ_m
  • Diamagnetic: χ < 0, μ_r < 1, repelled from strong fields (Bi, Cu, H₂O, Pb).
  • Paramagnetic: 0 < χ ≪ 1, μ_r > 1; Curie's law χ = C / T (Al, Na, O₂).
  • Ferromagnetic: χ ≫ 1, μ_r ≫ 1, domain structure; Curie-Weiss χ = C/(T - T_c) (Fe, Ni).
  • Hysteresis Loop: Retentivity B_r, Coercivity H_c; Soft iron for electromagnets, Steel/Alnico for permanent magnets.
