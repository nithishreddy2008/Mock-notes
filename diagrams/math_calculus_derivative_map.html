THE CALCULUS MAP — FROM SMOOTHNESS TO OPTIMUM

CUET UG · MATHEMATICS · CALCULUS

Gate 1 · Continuity at a point c

Three checks: f(c) exists · limx→c f(x) exists (left = right) · the limit equals f(c)
Everyday read: you can draw the graph through c without lifting the pen
Classic breaks: piecewise mismatches, 1/x at 0, greatest-integer jumps

Gate 2 · Differentiability at c

Test: the left and right derivatives at c must match — the graph is smooth, no corner
Order of ideas: differentiable ⇒ continuous; continuous ⇏ differentiable
Classic break: |x| at 0 — perfectly continuous, sharply cornered

THE DERIVATIVE TOOLKIT — SIX WAYS IN

Chain rule
dy/dx = dy/du · du/dx
peel the function from outside in
Inverse trig
d/dx sin⁻¹x = 1/√(1−x²)
tan⁻¹x → 1/(1+x²); cos⁻¹x is the negative twin
Implicit
differentiate both sides, collect dy/dx
x² + y² = 25 → dy/dx = −x/y
Exponential / log
d/dx eˣ = eˣ · d/dx ln x = 1/x
aˣ = aˣ ln a; logax = 1/(x ln a)
Logarithmic diff.
take ln of both sides first
the move for y = xˣ and f = u·v·w/(powers)
Parametric
dy/dx = (dy/dt)/(dx/dt)
both derivatives taken against the parameter t

Rate of change

dy/dx is a rate: how fast y responds to x
Time rates: dA/dt = dA/dr · dr/dt — chain through the geometry
Example: balloon r = 10, dr/dt = 2 → dA/dt = 40π

Increasing / decreasing

f' > 0 rising · f' < 0 falling on the interval
Routine: domain → f' → critical points → sign chart
Example: x³ − 12x rises, then falls, then rises again

Maxima & minima

Critical points: f' = 0 (or undefined) — candidates only
First test: f' changes + to − (max) or − to + (min)
Second test: f'' < 0 peak · f'' > 0 valley · f'' = 0 → inconclusive

TRAPS THE OPTIONS ARE BUILT AROUND

Continuous ⇏ differentiable — |x| settles it in one line
Chain rule: forgetting the inner derivative is the #1 slip
cos⁻¹x derivative is negative — the sign flip is the whole question
f'(c) = 0 is not a verdict — inflection points pass it too
f''(c) = 0 says "keep looking" — use the first-derivative test
Parametric flip: dy/dx = (dy/dt)/(dx/dt), not the reciprocal
