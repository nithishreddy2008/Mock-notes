Order & Degree Foundations
Core Taxonomy
Order = Max derivative index (n)
Degree = Power of (dⁿy/dxⁿ)
Order: The order of the highest-order derivative appearing in the differential equation. Order is ALWAYS defined for any legitimate DE.
Degree: The exponent/power to which the highest-order derivative is raised, AFTER the equation is cleared of radicals and fractional powers of derivatives.
Polynomial Requirement: The equation MUST be a polynomial equation in derivatives (y', y'', y'''). Powers must be non-negative integers (0, 1, 2, ...).
Radical Clearing Protocol:
y'' = [1 + (y')2]3/2
Square both sides:
(y'')2 = [1 + (y')2]3
→ Order = 2, Degree = 2
2
Undefined Degree Boundary Cases
NTA Traps
f(y', y'', ...) ∉ Polynomial
⇒ Degree is NOT DEFINED
Transcendental Derivatives: When a derivative is captured inside a non-algebraic function (trig, exp, log), degree fails the polynomial test.
Case 1: Exponential
y''' + y2 + ey' = 0
Order = 3. Degree = NOT DEFINED.
Case 2: Trigonometric
y'' + cos(y') = 0
Order = 2. Degree = NOT DEFINED.
Trap Bypass Test:
$sin(y') = x ⇒ y' = sin-1(x)$
Here derivative CAN be isolated! Degree = 1, Order = 1.
3
Formation from Families
Elimination
n Arbitrary Constants
⇒ n-th Order DE
The Arbitrary Constant Invariant: To form the DE of a family containing $n$ independent parameters, differentiate exactly $n$ times and eliminate all $n$ parameters.
1. Lines through origin (y = mx):
y' = m ⇒ y = (y')x ⇒ xy' - y = 0 (Order 1)
2. Family y = a·e2x + b·e-2x:
y' = 2a·e2x - 2b·e-2x
y'' = 4a·e2x + 4b·e-2x = 4y
$⇒ y'' - 4y = 0$ (Order 2, Degree 1)
Concentric Circles at Origin (x2 + y2 = r2):
2x + 2y·y' = 0 ⇒ x + y·y' = 0
4
General vs Particular Solutions
IVP & Conditions
General: n arbitrary constants
Particular: 0 arbitrary constants
General Solution: Contains as many essential arbitrary constants as the order of the differential equation (First order → 1 constant; second order → 2 constants).
Particular Solution: Obtained from the general solution by assigning specific values to constants via given initial/boundary conditions (y(x0) = y0).
Golden Rule for CUET MCQs:
- Number of constants in General Solution of order n = n.
- Number of constants in Particular Solution of order n = 0 (always zero!).
Example: $dy/dx = 3x^2 ⇒ y = x^3 + C$ (General). If $y(0) = 2 ⇒ C = 2 ⇒ y = x^3 + 2$ (Particular).
Order is ALWAYS defined & equal to max derivative index
Degree requires polynomial form in derivatives (no trig/exp of y')
Particular solution NEVER contains any arbitrary constants (Count = 0)
