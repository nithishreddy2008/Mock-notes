Geometric Foundations
Feasible Region & Convexity
Convex Polygon: All Corners Tested
Convex Set Invariant
The feasible region of an LPP is always a convex set. The line segment connecting any two feasible points lies entirely inside the region.
Bounded Feasible Region
Enclosed completely inside a circle of finite radius. Both Maximum and Minimum values ALWAYS exist at corner vertices (Theorem 2).
Unbounded Feasible Region
Extends infinitely into space in at least one direction. An optimal value may or may not exist; verification via the Open Half-Plane Test is mandatory!
Algorithm Engine
Step-by-Step Solving Protocol
  • Convert to Equalities: Replace inequality signs ($\le, \ge$) with straight line equations ($a x + b y = c$).
  • Plot Boundary Lines: Find intercept points $(c/a, 0)$ and $(0, c/b)$. Draw solid lines (since $\le, \ge$ include boundaries).
  • Determine Feasible Half-Planes: Test origin $(0, 0)$. If true, shade origin side; if false, shade opposite side. Restrict to Quadrant 1 ($x \ge 0, y \ge 0$).
  • Locate All Corner Points (Vertices): Solve pairs of simultaneous equations to find exact coordinates of all region vertices.
  • Evaluate Objective Function: Substitute every corner point $(x_k, y_k)$ into $Z = a x + b y$. Identify candidate $M = \max Z$ and $m = \min Z$.
  • Unbounded Check (if applicable): If region is unbounded, run Open Half-Plane Test before declaring candidate as final optimum.
Critical Rigor
The Open Half-Plane Test & Special Cases
Test for Maximum in Unbounded Region
Let candidate maximum be $M$. Draw dotted line $a x + b y = M$.
• If the open half-plane $a x + b y > M$ has NO common points with the feasible region $\implies \mathbf{M}$ is the true maximum.
• If it shares even one common point $\implies$ No Maximum Exists!
Test for Minimum in Unbounded Region
Let candidate minimum be $m$. Draw dotted line $a x + b y = m$.
• If the open half-plane $a x + b y < m$ has NO common points with the feasible region $\implies \mathbf{m}$ is the true minimum.
• If it shares points with the feasible region $\implies$ No Minimum Exists!
Multiple Optimal Solutions (Infinite Optima)
If $Z$ achieves the exact same optimal value at two adjacent vertices $A$ and $B$, then every point on the line segment $A B$ is also an optimal solution. Occurs when the slope of $Z$ equals the slope of a boundary constraint: $-a/b = -a_k/b_k$.
Fundamental Theorem 1
Let $R$ be the feasible region and $Z = a x + b y$ be the objective function. If $R$ is bounded, the optimal value of $Z$ must occur at a corner point (vertex) of $R$.
Fundamental Theorem 2
If the feasible region $R$ is bounded, then the objective function $Z$ has both a maximum and a minimum value on $R$, each occurring at a corner point.
Infeasible Problem (No Solution)
Occurs when the system of constraints has no common shaded region (intersection is the empty set $\emptyset$). Example: $x + y \le 1$ and $x + y \ge 3$ simultaneously.
