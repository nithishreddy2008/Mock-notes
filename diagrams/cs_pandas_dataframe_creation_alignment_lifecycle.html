Pandas Core Mechanics
1
Constructor Creation
Dict of Lists vs Series
d = {'A': [10, 20],
     'B': [30, 40]}
df = pd.DataFrame(d)
Keys → Columns · Arrays → Rows
# Dict of Series with index
s1 = pd.Series([1, 2], index=['r1', 'r2'])
df = pd.DataFrame({'C1': s1})
CUET Invariant: In a Dict of Lists, all lists must have equal length (or ValueError). In a Dict of Series, lengths can vary; missing entries fill with NaN!
2
Index Alignment
Automatic Union & NaN
s1 = pd.Series([10, 20], index=['a', 'b'])
s2 = pd.Series([30, 40], index=['b', 'c'])
s3 = s1 + s2
Resulting Index: ['a', 'b', 'c']
a : NaN (missing in s2)
b : 50.0 (20 + 30)
c : NaN (missing in s1)
CUET Invariant: Arithmetic aligns strictly by Index Label, NOT positional order! Unmatched labels produce NaN (float64).
3
Vectorized Operations
Element-wise & NaN Rules
# Scalar Broadcasting
df['Bonus'] = df['Salary'] * 0.10

# Boolean Filtering
high = df[df['Score'] >= 80]

# NaN Propagation
10 + np.nan → np.nan
No Python loops required!
CUET Invariant: Any arithmetic operation performed with NaN unconditionally evaluates to NaN. Use add(fill_value=0) to prevent NaN.
4
Indexing & Slicing
loc vs iloc Boundaries
# Label-based: loc[row, col]
df.loc['r1':'r3', 'A':'B']
★ INCLUDES 'r3' and 'B'!

# Positional: iloc[row, col]
df.iloc[0:3, 0:2]
★ EXCLUDES 3 and 2!
Direct: df['Col'] / df[['C1','C2']]
FATAL CUET TRAP: loc includes stop labels; iloc excludes stop indices! Column selection df['A'] returns Series; df[['A']] returns DataFrame.
Key Slicing Invariant: loc is Closed Interval [start, stop] · iloc is Half-Open Interval [start, stop)
