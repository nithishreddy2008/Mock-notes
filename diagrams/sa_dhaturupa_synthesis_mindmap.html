चित्रम् ३ · समग्र-मानचित्रम्
१. परस्मैपदि-धातवः (सामान्य-रूपाणि)
भू (भवति), गम् (गच्छति / लृटि गमिष्यति), पा (पिबति / पास्यति), स्था (तिष्ठति / स्थास्यति), दृश् (पश्यति / द्रक्ष्यति), नम् (नमति / नंस्यति), हस्, धाव्, लिख्, जीव्, पठ्; तिप्-तस्-झि प्रत्यय-संयोजनम्।
भू/गम् पा/स्था दृश्/नम् तिप्-तस्-झि
२. विशिष्टाः क्लिष्टाः परस्मैपदिनः
अस् (अस्ति, स्तः, सन्ति; आसीत्, स्यात्; लृटि भविष्यति); श्रु (शृणोति, शृणुतः, शृण्वन्ति; अशृणोत्, शृणुयात्); आप् (आप्नोति); शक् (शक्नोति); ज्ञा (जानाति, जानीतः, जानन्ति; अजानात्; जानीयात्); प्रच्छ् (पृच्छति / प्रक्ष्यति)।
अस् (अस्ति) ज्ञा (जानाति) श्रु (शृणोति) शक् (शक्नोति)
३. आत्मनेपदि-धातवः
लभ् (लभते, लभेते, लभन्ते; अलभत; लभताम्; लभेत; लप्स्यते); सेव् (सेवते; सेविष्यते); वन्द् (वन्दते); याच् (याचते); रुच् (रोचते / रोचिष्यते); वृत् (वर्तते); जन् (जायते; जनिष्यते); त-आथाम्-झ प्रत्यय-व्यवस्था।
लभ् (लभते) सेव् (सेवते) रुच् (रोचते) जन् (जायते)
४. उभयपदि-धातवः
कृ (करोति / कुरुते; अकरोत् / अकुरुत; करिष्यति / करिष्यते; करोतु / कुरुताम्; कुर्यात् / कुर्वीत); नी (नयति / नयते); पच् (पचति / पचते); दा (यच्छति / ददाति / दत्ते); भज् (भजति / भजते); क्रियाफल-स्वामित्व-भेदः।
कृ (करोति/कुरुते) नी (नयति/नयते) पच् (पचति/पचते) दा (ददाति/दत्ते)
५. पञ्च-लकार-व्यवस्था
लट् (वर्तमाने: पठति); लृट् (भविष्यति: पठिष्यति); लङ् (अनद्यतन-भूते: अपठत्, अडागमः); लोट् (आज्ञार्थे: पठतु, पठ); विधिलिङ् (कर्त्तव्ये: पठेत्); 'स्म' प्रयोगः (पठति स्म = अपठत्; लट् क्रिया भूतकाल-वाचिका भवति)।
लट् वर्तमान लृट् भविष्यत् लङ् भूतकाल स्म प्रयोगः
६. पुरुष-वचन-सङ्गतिः भ्रमाः च
प्रथमपुरुषः (सः/सा/भवत्); मध्यमपुरुषः (त्वम्/युवाम्/यूयम्); उत्तमपुरुषः (अहम्/आवाम्/वयम्); लृट् लकारे विकरण-लोपात् आदेश-निवृत्तिः (पा $\to$ पास्यति, दृश् $\to$ द्रक्ष्यति, स्था $\to$ स्थास्यति); कर्तृ-क्रिया-अन्वय-नियमाः।
पुरुष-सङ्गतिः भवत् योगे प्रथमः लृट् आदेश-लोपः अन्वय-नियमः
