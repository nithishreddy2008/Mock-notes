THE DIFFERENTIAL-EQUATION SOLVER'S LADDER

CUET UG · MATHEMATICS · DIFFERENTIAL EQUATIONS
RUNG 1 · EASIEST

Variable Separable

dy/dx = f(x) · g(y) — the two variables already live on different sides
Move: push every y with dy, every x with dx → integrate both sides → remember one + C. Example: dy/dx = xy/(1+x²) → y = C√(1+x²)
RUNG 2 · ONE SUBSTITUTION

Homogeneous (F(y/x))

dy/dx = F(y/x) — every term has the same degree; ratio-shaped
Move: put y = vx, so dy/dx = v + x·dv/dx → the equation becomes separable in v and x → integrate → substitute back. Test: F(λx, λy) = F(x, y)
RUNG 3 · THE ENGINE

Linear: dy/dx + Py = Q

y appears to the first power, no sin y or e^y — just a coefficient P
Move: IF = e∫P dx → then y · IF = ∫ Q · IF dx + C. Example: dy/dx + y/x = x² → IF = x → y = x³/4 + C/x

Order, Degree, and the Two Kinds of Answer

Order = highest derivative present. (d²y/dx²)³ + y' = 0 → order 2.
Degree = power of that highest derivative — only when the equation is polynomial in its derivatives. Same example → degree 3.
Not polynomial? Degree is not defined: (1 + (dy/dx)²)^(3/2) has order 1, no degree.
General solution = full family with arbitrary constants (A, B, C…). Particular = one member with constants fixed by conditions.
Verify any solution: differentiate it, substitute back — algebra must collapse to an identity.

The Integrating-Factor Engine (linear)

Match the shape dy/dx + P y = Q (P, Q functions of x — or constants)
Build IF = e∫ P dx — integrate P first, exponentiate second
Multiply through by IF — the left side becomes d/dx (y · IF) exactly
Integrate the right side: y · IF = ∫ Q · IF dx + C
Flip the form for dx/dy + P x = Q: same engine, P and Q in y, IF = e∫P dy

TRAPS THE OPTIONS ARE BUILT AROUND

Degree ≠ order — the power of the top derivative, not its count
Radical/fraction powers of derivatives kill the degree — "not defined"
Missing IF makes linear answers look almost right
IF of dy/dx + y/x is x, not ln x — exponentiate ∫P, never skip it
One +C per integration — general solutions carry their constant
y = vx needs the back-substitute — answers in v alone score zero
