1
Variable Separable Method
Method 1
h(y) dy = g(x) dx
⇒ ∫ h(y) dy = ∫ g(x) dx + C
Standard Reflex: Collect all y and dy terms on LHS, and all x and dx terms on RHS. Integrate both sides directly.
Classic Example:
dy/dx = (1 + y2)/(1 + x2)
⇒ dy/(1 + y2) = dx/(1 + x2)
⇒ tan-1(y) = tan-1(x) + C
Reducible to Separable:
dy/dx = f(ax + by + c)
Substitute u = ax + by + c
du/dx = a + b(dy/dx) = a + b·f(u)
⇒ ∫ du/[a + b·f(u)] = ∫ dx = x + C
2
Homogeneous Equations
Method 2
dy/dx = F(y/x)
Substitute: y = v·x ⇒ dy/dx = v + x(dv/dx)
Homogeneity Test: f(λx, λy) = λ0 f(x, y). Both numerator and denominator have identical degrees.
Execution Flow:
v + x(dv/dx) = F(v)
⇒ dv / [F(v) - v] = dx / x
Integrate and back-substitute v = y/x.
Type 2 Inversion Trap:
When equation contains x/y terms (e.g. ex/y):
Write as dx/dy = G(x/y)
Substitute: x = v·y ⇒ dx/dy = v + y(dv/dy)!
3
Linear DE & Integrating Factor
Method 3
dy/dx + P(x)·y = Q(x)
IF = e^(∫ P dx)
y · IF = ∫ [Q · IF] dx + C
Standard Form Verification: The coefficient of dy/dx MUST be unity 1. If x(dy/dx) + y = x3, divide by x first: dy/dx + (1/x)y = x2!
Type 1 Solution:
P = 1/x ⇒ IF = e∫ (1/x) dx = eln x = x
y·x = ∫ (x2·x) dx = x4/4 + C
Type 2 Dual Form:
dx/dy + P(y)·x = Q(y)
IF = e∫ P(y) dy
x·IF = ∫ [Q(y)·IF] dy + C
4
IF Logarithm Rules & Bernoulli
Speed Rules
e^(k·ln f(x)) = [f(x)]k
Bernoulli: dy/dx + Py = Qyn
Exponential-Log Identities:
• eln(sec x) = sec x
• e-ln x = eln(x-1) = 1/x
• e2 ln x = eln(x2) = x2
• e-2 ln(cos x) = sec2 x
Sign Error Alert: Writing e-ln x = -x is the #1 student error on NTA papers! It is 1/x.
Bernoulli Reduction:
y-n(dy/dx) + P·y1-n = Q
Put u = y1-n ⇒ [1/(1-n)] du/dx + P·u = Q
Converts to standard linear DE in u!
Always reduce coefficient of dy/dx to 1 BEFORE computing IF = e^∫Pdx
Remember exponential identity: e^(-ln x) = 1/x (NOT -x)
Use Type 2 (dx/dy + Px = Q) whenever y is linear and dy/dx is awkward
