Master Synthesis Mindmap: Advanced Pandas & Relational Data Operations

Comprehensive knowledge taxonomy across Sorting, Pivoting, GroupBy, Merging, and Cleaning

CUET Code 308 · Syllabus Mindmap
1. Sorting & Ranking
  • df.sort_values(by='col', ascending=True): Sorts rows by column values.
  • Multi-column sort: by=['Dept', 'Salary'], ascending=[True, False].
  • df.sort_index(axis=0/1): Reorders rows or columns by label.
  • inplace=True modifies object in-place; returns None.
2. Reshaping & Pivoting
  • df.pivot(index, columns, values): Reshaping without aggregation; fails on duplicates.
  • df.pivot_table(): Handles duplicates using aggfunc='mean'.
  • fill_value=0: Replaces empty intersection NaNs.
  • margins=True: Generates subtotal/grand total summary margins.
3. GroupBy Split-Apply-Combine
  • df.groupby('col'): Returns lazy DataFrameGroupBy object.
  • Standard aggregations: .sum(), .mean(), .count(), .std(), .min(), .max().
  • Multi-aggregation: g.agg({'A': ['min', 'max'], 'B': 'sum'}).
  • as_index=False keeps group keys as regular columns instead of index.
4. Merging & Relational Joins
  • pd.merge(df1, df2, on='key', how='inner/left/right/outer').
  • Mismatched keys: left_on='id1', right_on='id2'.
  • df1.join(df2): Index-based join; defaults to how='left'.
  • Requires lsuffix and rsuffix if column names clash.
5. Concatenation & Stacking
  • pd.concat([df1, df2], axis=0): Vertical row stack.
  • pd.concat([df1, df2], axis=1): Horizontal column stack.
  • ignore_index=True: Resets index to 0, 1, ..., n-1.
  • join='inner' retains only intersecting axis labels.
6. Advanced Cleaning & Nulls
  • Null masks: df.isna(), df.notnull(), df.isnull().sum().
  • Pruning: df.dropna(how='any'/'all', thresh=k).
  • Imputation: df.fillna(value, method='ffill'/'bfill').
  • Duplicates: df.duplicated() and df.drop_duplicates().
