1. Continuity & Differentiability
Foundations
Continuity at x = c (Three-Fold Test):
1. f(c) is defined.
2. limx→c⁻ f(x) = limx→c⁺ f(x) = L (Limit exists).
3. Limit value equals function value: L = f(c).
Differentiability at x = c:
Left derivative equals right derivative:
Lf'(c) = Rf'(c)
where f'(c) = limh→0 [f(c+h) - f(c)] / h.
The Fundamental Implication:
• Differentiability ⇒ Continuity (Always true!).
• Converse is strictly FALSE: A continuous function may fail to be differentiable at sharp corners/cusps (e.g. f(x) = |x| at x = 0).
Algebra of Continuous Functions:
If f and g are continuous at c, then f ± g, f · g, and f/g (for g(c) ≠ 0) are continuous. Every polynomial is continuous on ℝ.
Sharp corner/kink ⇒ continuous but not differentiable!
2. Advanced Differentiation Protocols
Techniques
Chain Rule (Function of Function):
If y = f(u) and u = g(x):
dy/dx = (dy/du) · (du/dx)
Implicit Differentiation:
When F(x, y) = 0 cannot be solved explicitly for y:
Differentiate term-by-term with respect to x, applying d/dx [g(y)] = g'(y) (dy/dx), then isolate dy/dx.
Logarithmic Differentiation (u(x)v(x)):
For variable base with variable exponent:
1. Take natural logarithm: ln y = v(x) ln u(x).
2. Differentiate implicitly:
dy/dx = y [v'(x) ln u(x) + v(x) u'(x) / u(x)].
Parametric Differentiation (x = f(t), y = g(t)):
• First derivative: dy/dx = (dy/dt) / (dx/dt) = g'(t) / f'(t).
• Second Derivative Trap (CRITICAL CUET TRAP!):
d²y/dx² = [d/dt (dy/dx)] · (dt/dx) = [d/dt (dy/dx)] / (dx/dt)
Never just divide y''(t) by x''(t)!
Parametric second derivative ALWAYS multiplies by (dt/dx) = 1/(dx/dt)!
3. Standard Derivative Vault
Formulas
Inverse Trigonometric Derivatives:
• d/dx [sin⁻¹ x] = 1 / √(1 - x²),   |x| < 1
• d/dx [cos⁻¹ x] = -1 / √(1 - x²),   |x| < 1
• d/dx [tan⁻¹ x] = 1 / (1 + x²),   x ∈ ℝ
• d/dx [cot⁻¹ x] = -1 / (1 + x²),   x ∈ ℝ
• d/dx [sec⁻¹ x] = 1 / (|x| √(x² - 1))
Exponential & Logarithmic:
• d/dx [eˣ] = eˣ  |  d/dx [aˣ] = aˣ ln a
• d/dx [ln x] = 1 / x  |  d/dx [logₐ x] = 1 / (x ln a)
Rolle's & Mean Value Theorem (Lagrange MVT):
If f is continuous on [a, b] and differentiable on (a, b):
• LMVT: ∃ c ∈ (a, b) such that f'(c) = [f(b) - f(a)] / (b - a).
• Rolle's Theorem: If also f(a) = f(b) ⇒ ∃ c ∈ (a, b) with f'(c) = 0.
Remember: "Co" functions (cos, cot, csc) always have a NEGATIVE derivative!
