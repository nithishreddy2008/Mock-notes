A Circular Queue Ring Buffer Lifecycle
• Circular Advance: ptr = (ptr + 1) % MAX
• Full / Overflow: (Rear + 1) % MAX == Front
• Empty / Underflow: Front == -1
• Element Count: (Rear - Front + MAX) % MAX + 1

Slots 0 and 1 were vacated by previous dequeues and are now successfully reused as $Rear$ wraps around past slot 5 back to 0 and 1, completely resolving the linear queue drift problem!

Specialized Deque Subtypes (High-Yield):

1. Input-Restricted Deque: Insertion is strictly confined to one end (Rear), while deletion is permitted at both Front and Rear.
2. Output-Restricted Deque: Deletion is strictly confined to one end (Front), while insertion is permitted at both Front and Rear.
Deque as Stack or Queue:
• Stack emulation: Use append() + pop() (LIFO at Rear).
• Queue emulation: Use append() + popleft() (FIFO from Rear to Front).
C Systems & Algorithmic Applications
1. CPU Round-Robin Scheduling:
Processes reside in a circular ready queue. The OS dispatcher grants CPU execution for a fixed time quantum. Preempted tasks re-enter at Rear.
2. BFS Graph / Tree Level-Order:
Nodes are visited layer-by-layer. A node is dequeued from Front, inspected, and its unvisited adjacent neighbors are enqueued at Rear.
3. Asynchronous I/O Buffering:
Media streaming (YouTube / Spotify) buffers chunks in a FIFO queue. Producer network thread enqueues; consumer audio hardware dequeues.
4. Print Spooler (`lpd`):
Multiple users dispatch print jobs. The printer driver serves requests strictly in arrival sequence via a FIFO spooler queue.
