1. Relations & Equivalence Classes
Binary Relations
Reflexive: (a, a) ∈ R for every a ∈ A. If even a single element lacks its self-loop (a, a), reflexivity fails completely.
Symmetric: (a, b) ∈ R ⇒ (b, a) ∈ R. Every forward directed pair must possess its exact mirror reverse.
Transitive: (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R. Every 2-step connected path must close directly.
Equivalence Relation: Satisfies Reflexive + Symmetric + Transitive simultaneously (e.g., equality, congruence, modular arithmetic).
Equivalence Class [a]: The set {x ∈ A : (x, a) ∈ R}. Fundamental Theorem: Equivalence classes form a mutually disjoint partition of set A whose union is A.
Counting Formulas for Set A with n elements:
• Total Relations: 2n² • Reflexive Relations: 2n(n-1) • Symmetric: 2n(n+1)/2 • Refl + Symm: 2n(n-1)/2
Empty relation ∅ on non-empty A is symmetric and transitive (vacuously true), but NOT reflexive.
2. Mapping Engine (Injective & Surjective)
Mappings
Injective (One-One): Distinct inputs produce distinct outputs. f(x1) = f(x2) ⇒ x1 = x2.
• Calculus Test: If f'(x) > 0 strictly (or < 0) on interval ⇒ strictly monotonic ⇒ one-one.
• Horizontal Line Test: Every horizontal line cuts graph at most once.
Surjective (Onto): Every codomain element is mapped. Range(f) = Codomain(B).
• Solve y = f(x) for x in terms of y; verify x ∈ Domain for every y ∈ Codomain.
Bijective (Invertible): Both Injective + Surjective. A function possesses an inverse f-1 if and only if it is bijective.
Counting Functions from A (|A|=m) to B (|B|=n):
• Total Functions: nm • Bijections (m=n): n! • One-One (m ≤ n): nPm = n! / (n-m)! (Zero if m > n) • Onto (m ≥ n): ∑ (-1)n-r nCr rm (Zero if m < n)
For finite sets with |A| = |B|: f is one-one ⇔ f is onto ⇔ f is bijective!
3. Composition & Inversion
Algebra of Functions
Composition (f ∘ g)(x) = f(g(x)):
Evaluated inside-out (g acts first, then f).
• Non-commutative: f ∘ g ≠ g ∘ f in general.
• Associative: (f ∘ g) ∘ h = f ∘ (g ∘ h).
• If both f and g are one-one (or onto), then f ∘ g is also one-one (or onto).
Reversal Law of Inverses:
(f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹
Notice the reversed order (analogous to the socks-and-shoes rule and transpose of matrices (AB)T = BT AT).
Graphical Symmetry of Inverses:
The graph of y = f-1(x) is the exact reflection of y = f(x) across the identity line y = x.
Intersection points of y = f(x) and y = f-1(x) always lie along y = x.
Common Trap: f-1(x) ≠ 1 / f(x)! f-1 is the inverse operation, while 1/f(x) is the algebraic reciprocal.
