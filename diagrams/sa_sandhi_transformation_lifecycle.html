संस्कृत-सन्धि-प्रक्रिया : पञ्च-सोपानात्मकः पाणिनीय-निर्णय-प्रवाहः

CUET UG संस्कृतम् (Code 325) · वर्णसन्निधि-परीक्षणात् पदनिष्पत्तिपर्यन्तं प्रक्रिया-प्रवाहः

चित्रम् २ · Process Lifecycle
सोपानम् १ · सन्निधिः
वर्ण-संनिकर्ष-परीक्षणम्
पदयोः सन्निधौ अर्धमात्राकालादपि न्यूनः व्यवधानरहितः कालः:
"परः संनिकर्षः संहिता"
(अष्टाध्यायी १.४.१०९)
पूर्वपदस्य अन्त्यवर्णः + उत्तरपदस्य प्रथमवर्णः परस्परं मिलतः।
→
सोपानम् २ · वर्गीकरणम्
पूर्ववर्ण-स्वरूप-निर्णयः
पूर्वपदस्य अन्त्यवर्णस्य प्रकृति-परीक्षणम्:
• यदि अच् (स्वरः) → स्वर-सन्धिः
• यदि हल् (व्यञ्जनम्) → व्यञ्जन-सन्धिः
• यदि विसर्गः (:) → विसर्ग-सन्धिः
प्रत्याहार-निर्धारणम् (अक्, इक्, एङ्, झल्, खर्)।
→
सोपानम् ३ · सूत्र-प्रवृत्तिः
पाणिनीय-नियम-संयोगः
परवर्णस्य साहचर्येण विशिष्य सूत्र-प्रवर्तनम्:
• सवर्ण अच्? → अकः सवर्णे दीर्घः
• असवर्ण अच्? → इको यणचि
• एङ् + ह्रस्व अ? → एङः पदान्तादति
• झल् + खर्? → खरि च (चर्त्वम्)
• अतो रोः + अशि? → हशि च / उत्वम्
→
सोपानम् ४ · रूपान्तरणम्
आदेशः एकादेशः आगमो वा
वर्णयोः विकारस्य पाणिनीया विधा:
• एकादेशः: द्वयोः स्थाने एकः (दीर्घ/गुण/वृद्धि/पूर्वरूप)
• आदेशः: शत्रुमद् विनाशकः (यण्/श्चुत्व/जश्त्व)
• आगमः: मित्रवत् प्रविष्टः (तुगागमः, नुडागमः)
• लोपः: दर्शनस्याभावः (रो रि, विसर्गलोपः)
→
सोपानम् ५ · निष्पत्तिः
शुद्ध-पद-निष्पत्तिः विच्छेदश्च
CUET परीक्षायाम् अर्थपूर्ण-विच्छेदस्य सिद्धिः:
• संधिः: देव + ऋषिः = देवर्षिः
• विच्छेदः: जगदीशः = जगत् + ईशः
• अपवादः: प्र + एजते = प्रेजते (पररूपम्)
• प्रकृतिभावः: हरी एतौ = हरी एतौ (प्लुतप्रगृह्याः)
