ORDER Written Lexical Syntax vs Logical Execution Pipeline
1. Written Syntax Order:
SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
2. Logical Execution Order:
FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT
Key Consequence:
Aliases defined in SELECT (Stage 5) are completely invisible to WHERE (Stage 2) because WHERE executes beforehand!

⚠️ Fatal CUET Trap: WHERE vs HAVING
WHERE filters individual records before aggregation and cannot contain aggregate functions like COUNT() or AVG() (e.g., WHERE AVG(Salary) > 50000 is a fatal SQL syntax error!). HAVING filters aggregate groups after grouping and is evaluated at Stage 4.
