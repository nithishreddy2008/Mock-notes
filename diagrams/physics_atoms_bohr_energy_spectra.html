Rutherford Alpha Scattering
Distance of Closest Approach (Head-On Collision, b = 0)
K_α = (1 / (4πε₀)) · (2 Z e² / r₀) ⟹ r₀ = (2 Z e²) / (4πε₀ K_α)
For 5.5 MeV α on Gold (Z = 79), r₀ ≈ 4.13 × 10⁻¹⁴ m (~ 41.3 fm). Upper limit of nuclear size.
  • Scattering Number Law: Number of α-particles scattered at angle θ satisfies: N(θ) ∝ 1 / sin⁴(θ/2).
  • Impact Parameter: $b = \frac{Z e^2 \cot(\theta/2)}{4\pi\epsilon_0 K_\alpha}$. Large $b \implies \theta \approx 0^\circ$; $b = 0 \implies \theta = 180^\circ$.
  • Rutherford Model Failure: Classical electrodynamics dictates accelerating electrons continuously radiate energy, spiraling into nucleus in $10^{-8}\text{ s}$. Cannot explain atomic stability or discrete line spectra!
Bohr Postulates & Hydrogen Orbitals
Bohr's 3 Foundational Postulates
1. Stable Non-Radiating Orbits: Centripetal force = Electrostatic pull: $m v^2 / r = (1/4\pi\epsilon_0) (Z e^2 / r^2)$.
2. Angular Momentum Quantization: $L = m v r_n = \frac{n h}{2\pi} = n \hbar$ ($n = 1, 2, 3 \dots$).
3. Frequency Condition: $E_2 - E_1 = h \nu = (h c) / \lambda$.
Core Orbital Quantities for Hydrogenic Atoms:
Parameter Formula / Scaling Ground State (H, Z=1, n=1)
Radius ($r_n$) $r_n = \frac{\epsilon_0 n^2 h^2}{\pi m Z e^2} = 0.529 \frac{n^2}{Z}\text{ \AA}$ $a_0 = 0.529\text{ \AA} = 0.0529\text{ nm}$
Speed ($v_n$) $v_n = \frac{Z e^2}{2 \epsilon_0 n h} = 2.18 \times 10^6 \frac{Z}{n}\text{ m/s}$ $v_1 = c / 137 \approx 2.18 \times 10^6\text{ m/s}$
Kinetic ($K$) $K_n = \frac{1}{2} m v_n^2 = +13.6 \frac{Z^2}{n^2}\text{ eV}$ $K_1 = +13.6\text{ eV}$
Potential ($U$) $U_n = -\frac{Z e^2}{4\pi\epsilon_0 r_n} = -27.2 \frac{Z^2}{n^2}\text{ eV}$ $U_1 = -27.2\text{ eV}$
Total ($E_n$) $E_n = K_n + U_n = -13.6 \frac{Z^2}{n^2}\text{ eV}$ $E_1 = -13.6\text{ eV}$
Gold-Standard Energy Relation:
$E_n = -K_n = U_n / 2 \iff U_n = -2 K_n = 2 E_n$
(Negative total energy signifies that the electron is electrostatically bound to the nucleus!)
Hydrogen Line Spectra & Rydberg Formula
Rydberg Formula for Hydrogenic Systems
1/λ = R Z² (1/n₁² - 1/n₂²)
Rydberg constant: R = 1.097 × 10⁷ m⁻¹. (1/R ≈ 912 Å).
Series n₁ n₂ Spectral Region Shortest λ (Limit)
Lyman 1 2, 3, 4, ... Ultraviolet (UV) $R / 1 \implies 912\text{ \AA}$
Balmer 2 3, 4, 5, ... Visible Light $4 / R \implies 3646\text{ \AA}$
Paschen 3 4, 5, 6, ... Near Infrared $9 / R \implies 8208\text{ \AA}$
Brackett 4 5, 6, 7, ... Infrared (IR) $16 / R \implies 14592\text{ \AA}$
Pfund 5 6, 7, 8, ... Far Infrared $25 / R \implies 22800\text{ \AA}$
CUET Speed Formula:
Longest λ (first line, n₂ = n₁+1):
$1/\lambda_\text{max} = R (1/n_1^2 - 1/(n_1+1)^2)$
Shortest λ (series limit, n₂ = ∞):
$1/\lambda_\text{min} = R / n_1^2 \implies \lambda_\text{min} = n_1^2 / R$
Number of Spectral Lines: When an electron de-excites from state $n$ to ground state ($n=1$), maximum emitted lines: N = n(n - 1) / 2.
