CUET UG GENERAL APTITUDE TEST

Analogies & Sequences

Analogy: name the relationship in WORDS first — then apply it to the third term
Series: differences → ratios → letter positions; the pattern must fit EVERY step
Alphabet anchor: EJOTY = 5, 10, 15, 20, 25 for instant letter positions

Coding–Decoding

Letter-shift codes: compare sample word and code letter by letter — find the shift
Check the shape: same length? reversed? swapped pairs? The shape is the first clue
Apply, then verify: code the new word, then reverse-check on the sample

Syllogisms

Venn first, feel never: draw circles for every statement before judging
Must follow = true in ALL diagrams, not just your favourite one
"Some" promises nothing more: some A are B does NOT make some B-relation with C follow

Blood Relations

Tree, not memory: squares for males, circles for females, one clue per arrow
Speaker first: pin down the speaker's gender before decoding relations
Word traps: "only son" is not "only child"; "mother's brother" is not "father's brother"

Direction Sense

Compass cross on paper: mark N up, then draw every leg as an arrow
Displacement ≠ distance: straight line from start vs total path walked
3-4-5 shortcut: 3 km north + 4 km east = 5 km from start

Puzzles & Scoring Habits

Slot table: fix the definite clue first, chain from it, re-read every clue at the end
Facing direction first — it flips every left/right clue in seating puzzles
Marking maths: +5 right, −1 wrong — reasoning rewards method, so attempt after drawing

Traps that catch most students

Category instead of relationship in analogies — "works at" beats "is a profession"
One-gap pattern trust — a series pattern must survive all terms, not just the last gap
Listener-side relations — relations belong to the speaker, always
Distance vs displacement — read which one the question actually asks
