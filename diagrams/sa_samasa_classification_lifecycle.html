चित्रम् २ · Process Lifecycle
सोपानम् १ · पदच्छेदः
समस्तपदस्य विभाजनम्
समस्तपदं दृष्ट्वा पूर्वपदं उत्तरपदं च विभज्यते:
• पूर्वपदम्: आदिमः शब्दः
• उत्तरपदम्: अन्तिमः शब्दः
• सुपो धातुप्रातिपदिकयोः (२.४.७१) सूत्रेण समासे पूर्वपदस्य विभक्ति-लोपो जातः, तस्याः पुनरुद्धारः।
→
सोपानम् २ · प्राधान्यम्
पदार्थ-प्राधान्य-परीक्षणम्
वाक्ये कस्य पदस्य अर्थः मुख्यः अस्ति?
• पूर्वपदार्थः? → अव्ययीभावः
• उत्तरपदार्थः? → तत्पुरुषः/कर्म/द्विगु
• उभयपदार्थः? → द्वन्द्वः
• अन्यपदार्थः? → बहुव्रीहिः
→
सोपानम् ३ · लक्षणम्
विशेष-चिह्नानां मिलनम्
पदयोः व्याकरणिक-सङ्केतानां शोधनम्:
• पूर्वपदे अव्ययम्? → उप, निर्, अनु, यथा
• पूर्वपदे सङ्ख्या? → पञ्च, त्रि, अष्ट
• विशेषण-विशेष्यः? → नील + उत्पलम्
• 'च' संयोजनम्? → रामश्च कृष्णश्च
• यस्य/येन विग्रहः? → अन्यपदार्थः
→
सोपानम् ४ · अपवादः
विशिष्टापवाद-परीक्षणम्
CUET घातक-भ्रमाणां निराकरणम्:
• सङ्ख्या + नदी? → नदीभिश्च (अव्ययीभावः, न द्विगुः!)
• पीताम्बरः (हरिः) vs पीताम्बरम् (वस्त्रम्)
• नञ्: व्यञ्जने 'अ' (अब्राह्मणः), स्वरे 'अन्' (अनश्वः)
• उपपद: क्रियां विना विग्रहाभावः
→
सोपानम् ५ · विग्रहः
लौकिक-विग्रह-निष्पत्तिः
परीक्षा-प्रश्ने शुद्ध-वाक्यस्य निर्माणम्:
• उपगङ्गम् → गङ्गायाः समीपम्
• राजपुरुषः → राज्ञः पुरुषः
• घनश्यामः → घन इव श्यामः
• पञ्चपात्रम् → पञ्चानां पात्राणां समाहारः
• चक्रपाणिः → चक्रं पाणौ यस्य सः
