Cyber Threats & Defense Taxonomy Matrix

CUET UG Computer Science (Code 308) · Malware Propagation, User Action Dependency, Impact & Defense Mechanisms

NTA Threat Invariants
Threat Category Propagation Vector User Action? Payload Damage Mechanism Primary Defense CUET Exam Distinguisher
Computer Virus Attaches to executable host files (`.exe`, `.docx`) Yes (Must run file) Corrupts files, modifies boot sector, wipes disks Signature Antivirus Parasitic; cannot propagate without host file execution
Computer Worm Network ports & OS socket vulnerabilities No (Self-propagates) Exhausts network bandwidth, creates botnet zombies Patching & Firewalls Standalone; replicates automatically across network links
Trojan Horse Disguised as useful software (games, cracks) Yes (User installs) Installs backdoors, disables firewalls, rootkits App whitelisting Does not replicate; relies entirely on deception
Ransomware Phishing attachments, drive-by downloads Yes (Opens link) Encrypts user data using asymmetric ciphers (AES/RSA) Offline backups Demands cryptocurrency ransom for decryption key
Spyware / Keylogger Bundled with freeware, malicious browser ads Yes (Silent install) Logs keystrokes, steals passwords & credentials Anti-spyware tools Stealth surveillance; transmits telemetry to remote C2
Phishing Spoofed emails, fake banking landing pages Yes (Enters info) Harvests login credentials, 2FA codes, credit cards 2FA & User awareness Social engineering trickery; relies on user credulity
Pharming DNS cache poisoning, local `hosts` file modification No (URL is valid) Silently redirects correct URL to counterfeit server IP DNSSEC verification Technical attack; user types 100% correct URL but redirected
DoS / DDoS Flooding packet streams (SYN flood, UDP storm) No (Target server) Exhausts server CPU/bandwidth, causes service outage Rate-limiting & CDN Target is availability; does not steal or corrupt data
Core Distinctions: Virus (Host-dependent) vs Worm (Self-replicating) vs Trojan (Non-replicating disguise) vs Pharming (DNS redirection)
