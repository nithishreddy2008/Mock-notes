Comprehensive Mindmap
1
Malware Taxonomy
• Virus: Parasitic code attaching to host files (.exe); needs user to execute.
• Worm: Standalone, self-replicating code exploiting network sockets. Bandwidth hog.
• Trojan: Disguised as legitimate utility; opens backdoors. Never replicates.
• Ransomware: Cryptographically locks files; demands ransom.
• Spyware: Secret keylogger tracking user behavior.
2
Cyber Attack Vectors
• DoS / DDoS: Traffic flooding (SYN flood, UDP storm) via zombie botnets. Hits Availability.
• Phishing: Fraudulent emails spoofing trusted entities.
• Pharming: DNS poisoning redirecting valid URL to fake IP.
• Spoofing: IP / MAC / Email address forgery.
• MitM: Packet interception & eavesdropping.
3
Cryptography & PKI
• Symmetric: Single shared secret key (AES, DES). Fast.
• Asymmetric: Public key encrypts, Private key decrypts (RSA, ECC). Slower, solves key exchange.
• Hashing: One-way digest (SHA-256). Proves Integrity.
• Digital Signature: Hash encrypted with Sender Private Key (Authenticity & Non-Repudiation).
• Digital Certificate: CA-signed binding of public key.
4
Firewalls & Defenses
• Packet Filter: L3/L4 rules (IP, Port, Protocol). Stateless.
• Stateful Inspection: Tracks active TCP 3-way handshakes.
• Application Proxy: L7 deep packet inspection (DPI).
• Antivirus: Signature matching, heuristic behavioral scanning.
• DMZ: Demilitarized subnetwork isolating public servers.
5
Web Security & Identity
• HTTPS (Port 443): HTTP over TLS/SSL encryption.
• Cookies: Session (RAM) vs Persistent (Disk) vs 3rd Party (Tracking). Can be hijacked.
• Authentication: 2FA / MFA combining Knowledge (password), Possession (OTP/token), Inherence (biometrics).
• Digital Footprints: Active (posts) vs Passive (IP logs).
6
Cyber Law & Ethics (IT Act 2000)
• IT Act 2000: Legal recognition of electronic records & digital signatures. 2008 amendments.
• Hacker vs Cracker: Ethical white-hat testing vs malicious criminal intrusion.
• IPR: Copyright (code), Patent (algorithm), Trademark (brand).
• Offenses: Section 66 (Hacking), 66E (Privacy), 43 (Tampering).
