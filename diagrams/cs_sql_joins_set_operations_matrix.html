INNER / CROSS Equi-Joins & Cross Products
INNER JOIN ... ONEqui-Join
Pairs tuples satisfying join condition. Discards all non-matching dangling tuples. Degree: n1 + n2.
NATURAL JOINEqui-Join
Implicitly matches on all identically named columns. Projects out duplicate common columns! Degree: n1 + n2 - k.
CROSS JOINCartesian Product
Pairs every row in R with every row in S without condition. Degree: n1 + n2. Cardinality: m1 × m2.
OUTER JOINS Preserving Dangling Tuples
LEFT OUTER JOINPreserves Left
Retains all tuples of Left table R. Unmatched rows are padded with NULL for all Right table S attributes.
RIGHT OUTER JOINPreserves Right
Retains all tuples of Right table S. Unmatched rows are padded with NULL for all Left table R attributes.
FULL OUTER JOINPreserves Both
Preserves unmatched tuples from both relations with NULL padding. Emulated in MySQL via LEFT JOIN UNION RIGHT JOIN.
SET OPS Union & Set Operations
UNION vs UNION ALLUnion Compat.
UNION: Combines query results and purges duplicates. UNION ALL: Retains all duplicate rows (faster execution!).
INTERSECT & EXCEPTSet Logic
INTERSECT: Returns rows common to both queries. EXCEPT (MINUS): Returns rows in query 1 not present in query 2.
Union CompatibilityPrecondition
Both queries must have identical column counts and corresponding columns must have compatible data types.
