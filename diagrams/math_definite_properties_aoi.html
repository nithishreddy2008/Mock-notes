1. The King's Property & Interval Splitting
Core Definite Rules
∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫꜀ᵇ f(x) dx P2: Modulus & Step Functions
∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b − x) dx P3: General King's Rule
∫₀ᵃ f(x) dx = ∫₀ᵃ f(a − x) dx P4: Standard King's Rule
I = ∫₀^(π/2) sinⁿx / (sinⁿx + cosⁿx) dx = π / 4 King's Rule Symmetry Shortcut
I = ∫₀^(π/2) ln(sin x) dx = −(π / 2) ln 2 Euler's Standard Constant
King's Algorithm: Add I + I = ∫ [f(x) + f(a+b−x)] dx. Integrand collapses to constant 1! 2I = b − a
2. Queen's Property, Symmetries & Leibniz Rule
Symmetry & Derivatives
Queen's Property (∫₀^(2a) f(x) dx):
• If f(2a − x) = f(x) ⟹ 2 ∫₀ᵃ f(x) dx.
• If f(2a − x) = −f(x) ⟹ 0. (Instant zero cancellation in CUET!)
Even vs Odd Function Symmetry (∫₋ₐᵃ f(x) dx):
• Even [f(−x) = f(x)]: 2 ∫₀ᵃ f(x) dx.
• Odd [f(−x) = −f(x)]: 0. (E.g. ∫₋₁¹ x³ √(1−x²) dx = 0 automatically).
Leibniz Differentiation Under Integral Sign:
d/dx [∫_{u(x)}^{v(x)} f(t) dt] = f(v(x)) · v'(x) − f(u(x)) · u'(x)
Periodic Property: If f(x + T) = f(x), then ∫₀^(nT) f(x) dx = n ∫₀ᵀ f(x) dx. Periodicity Trick
3. Area Under Curves & Standard Shapes
Area Geometry
Area = ∫ₐᵇ |y| dx (Vertical) | ∫꜀ᵈ |x| dy (Horizontal) Absolute Sign Protocol
Circle: x² + y² = r² ⟹ Total Area = π r² Quadrant = (1/4) π r²
Ellipse: x²/a² + y²/b² = 1 ⟹ Total Area = π a b Quadrant = (1/4) π a b
Sine/Cosine Arch: Area of 1 loop of sin x from 0 to π = 2 sq units Single Arch = 2
Crossing the Axis: When y changes sign at c, Area = ∫ₐᶜ y dx + |∫꜀ᵇ y dx|. Never cancel! Sign Trap
4. Area Between Curves & CUET Shortcuts
Speed Shortcuts
General Formula: Area = ∫ₐᵇ [y_upper(x) − y_lower(x)] dx.
Step 1: Equate curves to find intersection limits x = a, b. Step 2: Integrate upper minus lower.
Shortcut 1: Two Orthogonal Parabolas:
Area bounded between y² = 4ax and x² = 4by is: Area = 16 a b / 3.
(E.g., y² = 4x and x² = 4y has a=1, b=1 ⟹ Area = 16/3 sq units).
Shortcut 2: Parabola and Secant Line:
Area bounded between y² = 4ax and y = mx is: Area = 8 a² / (3 m³).
Area bounded between y² = 4ax and its Latus Rectum (x = a) is: Area = 8 a² / 3.
Parabola shortcut saves 2 full minutes of integration and limits evaluation in CUET! 16ab/3 Formula
