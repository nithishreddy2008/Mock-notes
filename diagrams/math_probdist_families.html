BINOMIAL

n fixed tries, success/failure each time, constant p
P(X = r) = C(n, r) pr qn−r,   q = 1 − p
Mean: np  ·  Variance: npq  ·  SD: √(npq)
Fires when: "in n tosses / draws / shots, find P(exactly r successes)"
Example: 5 tosses, P(exactly 2 heads) = C(5,2)(1/2)⁵ = 5/16

POISSON

rare events in a fixed window — calls, accidents, typos per page
P(X = r) = e−λ λr / r!
Mean: λ  ·  Variance: λ (the signature: they are EQUAL)
Fires when: n is huge, p is tiny, the rate λ = np is the only number given
Example: λ = 2 → P(X = 0) = e−2 ≈ 0.135

NORMAL

continuous bell — heights, marks, measurement error
z = (x − μ) / σ — the standard normal variate
Area rule: μ ± 1σ → 68% · μ ± 2σ → 95% · μ ± 3σ → 99.7%
Fires when: a continuous measurement with bell behaviour is described
Note: P(X = exact value) = 0 — only intervals carry area

Discrete random variables — the table comes first

Build: list every value X can take, attach each probability from the story.
Police: every pᵢ in [0, 1] and the column sums to exactly 1 — check before anything else.
Expectation: E(X) = Σ xᵢpᵢ — the long-run average per trial.
Variance: Var(X) = Σ xᵢ²pᵢ − (E(X))² — subtract the squared mean, always.
Worked: two coins, X = heads → E = 1, Var = ½.

TRAPS THE OPTIONS ARE BUILT AROUND

Mean = variance = λ is POISSON only — never binomial, never normal
Binomial mean np, not n(1−p) — success probability, not failure
q = 1 − p — forgetting the flip breaks every binomial term
P(X = x) = 0 for continuous X — only P(a < X < b) has area
z uses (x − μ)/σ — flipped subtraction inverts the tail
e^(−λ) λʳ / r! — missing e^(−λ) is the classic Poisson slip
