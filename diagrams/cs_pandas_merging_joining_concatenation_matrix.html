Comparative Architecture: pd.merge() vs df.join() vs pd.concat()

Systematic matrix of Pandas relational data combinations, alignment axes, and syntax rules

CUET Code 308 · High-Yield Matrix
Architectural Feature pd.merge() (Database Join) df.join() (Index-Based Join) pd.concat() (Physical Stacking)
Primary Operation Type Relational SQL-style joins matching on common column keys or index labels. Convenience join wrapper matching left columns to right DataFrame index. Physical gluing / binding of Series or DataFrames along an axis.
Default Matching Key Intersection of column names present in both DataFrames (common columns). Row index of both DataFrames (or caller's column onto caller index). None (aligns on row index if axis=1; aligns on column names if axis=0).
Default Join Mechanism how='inner' (retains only rows with keys matching in both tables). how='left' (retains all rows of left DataFrame; fills NaNs on right). join='outer' (preserves union of all indices/columns across inputs).
Axis Orientation Implicit horizontal column merge (synthesizes wider 2D grid). Horizontal column join along Axis 1 (adds columns horizontally). Explicit axis control: axis=0 (stack rows), axis=1 (stack columns).
Handling Column Clashes Appends suffixes=('_x', '_y') automatically to duplicate column names. Raises ValueError unless lsuffix and rsuffix are specified. Keeps duplicated column names in output grid (MultiIndex columns possible).
CUET Fatal Exam Trap Specifying non-existent column in on='key' throws instant KeyError. Default is left join, unlike merge() which defaults to inner join. Index labels are preserved by default; use ignore_index=True to reset.
