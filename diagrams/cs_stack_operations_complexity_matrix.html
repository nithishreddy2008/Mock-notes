1 Stack ADT & Primitive Operations
Element C (Top of Stack) ← TOP
Element B
Element A (Stack Base)
  • push(item): Adds an element to the logical top. Shifts Top pointer to $(Top + 1)$. Triggers Overflow if capacity is bounded and full.
  • pop(): Removes and returns the top element. Shifts Top to $(Top - 1)$. Triggers Underflow if stack is already empty.
  • peek() / top(): Returns the top item without removing it. Essential for evaluating precedence in expression conversion.
  • is_empty(): Returns Boolean `True` if element count equals 0. Guard against underflow runtime exceptions.
  • size(): Returns the total number of elements currently residing on the stack.
2 Python Implementation Paradigms
Python Dynamic List (`list`) Standard / CUET Default
s.append(x) | s.pop() | s[-1]
Uses dynamic contiguous array. Amortized $O(1)$ push/pop at the end. Over-allocation resizing creates rare $O(N)$ memory copies. Guard: `if not s: Underflow`.
collections.deque (Double-ended Queue) High Performance
dq.append(x) | dq.pop() | dq[-1]
Doubly-linked block buffer (64 items per node). Strictly $O(1)$ push/pop with zero resizing latency spikes. Superior memory efficiency for massive pipelines.
queue.LifoQueue Thread-Safe
q.put(x) | q.get() | q.empty()
Synchronized wrapper with mutex locks. Enforces thread safety in multi-threaded concurrency at the cost of execution locking overhead.

CUET Fatal Trap: List Index 0 as Stack Top!
If a program implements stack push via `list.insert(0, item)` and pop via `list.pop(0)`, every operation forces an $O(N)$ memory element shift across the entire array! The Pythonic stack strictly treats index `-1` (end of list) as the Top of Stack ($O(1)$ amortized).
