Exception Handling Control Flow try-except-else-finally
1

try block

Guarded code executes. If error occurs, normal execution halts immediately; jumps to matching except.

2

except Class as err

Catches specific exception. Evaluated top-to-bottom. Most specific exceptions must precede broad parents.

3

else clause

Executes strictly when zero exceptions were raised in the try block. Avoids masking unexpected errors.

4

finally clause

Always executes unconditionally before leaving construct (closing files, releasing locks), even if unhandled error or return occurred.
