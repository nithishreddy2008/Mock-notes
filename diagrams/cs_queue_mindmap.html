QUEUE ADT

FIFO Architecture

1. Core ADT & FIFO Rules

  • FIFO Access Rule: First-In, First-Out. Insertion at Rear, extraction at Front.
  • Pointers: $Front$ (points to first active element), $Rear$ (points to last added).
  • Empty State: $Front = -1, Rear = -1$ (or $Front > Rear$).
  • Linear Queue Drift: $Rear$ reaches $Max - 1$, causing false overflow despite free front slots.

2. Double-Ended Queue (Deque)

  • Bi-Directional Operations: Insert & delete at both Front and Rear ($O(1)$).
  • Input-Restricted Deque: Insert allowed only at Rear; delete allowed at Front and Rear.
  • Output-Restricted Deque: Delete allowed only at Front; insert allowed at Front and Rear.
  • Universal ADT: Can natively emulate both Stacks (LIFO) and Queues (FIFO).

3. Implementation Paradigms

  • collections.deque: Doubly-linked blocks; strict $O(1)$ append, popleft.
  • Python List: append() ($O(1)$) + pop(0) ($O(N)$ linear trap!).
  • Linked Queue: Head = Front ($O(1)$ pop), Tail = Rear ($O(1)$ append).
  • Priority Queue: Heap-backed ordering; $O(log N)$ enqueue/dequeue via heapq.

4. Circular Queue Ring Buffers

  • Ring Geometry: Modulo arithmetic $ptr = (ptr + 1) mod Max$.
  • Full / Overflow Condition: $(Rear + 1) mod Max == Front$.
  • Empty / Underflow Condition: $Front == -1$.
  • Memory Reclaim: Re-utilizes vacated memory slots at index 0 after front dequeues.

5. The Seven Fatal CUET Traps

  • List pop(0) Anti-Pattern: Destroys efficiency from $O(1)$ to $O(N)$ due to memory shifts.
  • False Overflow Pitfall: Linear queue rejecting inserts when $Rear == Max-1$.
  • Deque Subtype Inversion: Confusing Input-Restricted with Output-Restricted rules.
  • Modulo Parentheses Bug: (Rear + 1) % Max vs Rear + 1 % Max.

6. Systems & Algorithm Applications

  • CPU Round-Robin: Time-sliced process execution ready queue.
  • BFS Graph Traversal: Level-by-level shortest unweighted path traversal.
  • Print Spooling: Printer jobs served in chronological FIFO submission order.
  • I/O Streams: Audio/video streaming buffers and producer-consumer pipes.
