Module 1
Vectors & Projections
Vector Representation
a = a1·i + a2·j + a3·k
|a| = √(a1² + a2² + a3²)

Unit vector: â = a / |a| with |â| = 1.

Collinearity Condition
a = λb ⟺ a1/b1 = a2/b2 = a3/b3

Two non-zero vectors are collinear/parallel if their components are proportional.

Scalar Projection
Proj of a on b = (a · b) / |b| = a · b̂

Projection is a scalar quantity. Can be positive, zero, or negative.

Vector Projection
Vector Proj = [(a · b)/|b|²] · b

Multiply the scalar projection by the unit vector b̂.

Projection Trap: Projection on b has |b| in denominator, NOT |a|!
Module 2
Dot (Scalar) Product
Definition & Angle
a · b = |a||b| cos θ
a · b = a1b1 + a2b2 + a3b3
cos θ = (a · b) / (|a||b|)
Orthogonality Condition
a ⊥ b ⟺ a · b = 0

Non-zero vectors are perpendicular if and only if their scalar product is zero.

Core Algebraic Identities
|a + b|² = |a|² + |b|² + 2(a · b)
|a - b|² = |a|² + |b|² - 2(a · b)
|a + b|² + |a - b|² = 2(|a|² + |b|²)
Cauchy-Schwarz Inequality
|a · b| ≤ |a||b|
If a + b + c = 0, take dot with (a+b+c) to evaluate 2(a·b + b·c + c·a) = -(|a|² + |b|² + |c|²).
Module 3
Cross (Vector) Product
Definition & Determinant
a × b = |a||b| sin θ · n̂
a × b = det[i, j, k; a1, a2, a3; b1, b2, b3]

Anti-commutative: b × a = -(a × b).

Parallelism Condition
a ∥ b ⟺ a × b = 0

Parallel non-zero vectors yield zero cross product.

Geometric Applications (Area)
Area(Δ ABC) = (1/2) |AB × AC|
Area(Parallelogram) = |a × b| (sides)
Area(Parallelogram) = (1/2)|d1 × d2| (diags)
Lagrange's Identity
|a × b|² = |a|²|b|² - (a · b)²
Unit vector perpendicular to both a and b: ±(a × b) / |a × b|.
Module 4
Scalar Triple Product
Box Product Formula
[a b c] = a · (b × c)
[a b c] = det[a1,a2,a3; b1,b2,b3; c1,c2,c3]
Cyclic Permutation
[a b c] = [b c a] = [c a b]
[b a c] = -[a b c]

If any two vectors are identical or parallel, [a a b] = 0.

Coplanarity Condition
a, b, c coplanar ⟺ [a b c] = 0

Crucial for checking if 4 points or 3 vectors lie in one plane.

Volumes
Vol(Parallelepiped) = |[a b c]|
Vol(Tetrahedron) = (1/6) |[a b c]|
Linear Combo Identity: [a+b, b+c, c+a] = 2 [a b c]. Constant CUET MCQ!
Dot product measures directional alignment (scalar: work, angle, projection)
Cross product constructs normal vector (vector: torque, area of plane)
Scalar triple product determines 3D volume & coplanarity: [a b c] = 0
