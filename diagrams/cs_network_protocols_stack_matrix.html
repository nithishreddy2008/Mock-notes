NTA Core Standards
Protocol Layer (OSI / TCP-IP) Port No. Transport Operational Function CUET High-Yield Trap
HTTP (Hypertext Transfer) L7 App / Application TCP 80 TCP Transfers plaintext web documents Stateless protocol; uses cookies for state tracking
HTTPS (HTTP Secure) L7 App / Application TCP 443 TCP Encrypted web traffic via TLS/SSL Uses asymmetric key for handshake, symmetric for data
FTP (File Transfer) L7 App / Application 20 & 21 TCP Transfers files between client & server Port 21 for Control/Commands, Port 20 for actual Data
DNS (Domain Name System) L7 App / Application 53 UDP / TCP Translates human names to IP addresses Queries use UDP 53; Zone transfers use TCP 53
SMTP (Simple Mail Transfer) L7 App / Application TCP 25 / 587 TCP Pushes outgoing email between servers *Push* protocol only; cannot retrieve mail from server
POP3 (Post Office Protocol v3) L7 App / Application TCP 110 / 995 TCP Downloads email to single device Deletes mail from server upon download (no multi-sync)
IMAP (Internet Message Access) L7 App / Application TCP 143 / 993 TCP Two-way synchronized email access Keeps mail on server; allows multi-client folder sync
Telnet vs SSH L7 App / Application 23 vs 22 TCP Remote terminal CLI access Telnet transmits plaintext credentials; SSH is fully encrypted
TCP vs UDP L4 Transport Host Ports — Host-to-host process delivery TCP: 3-way handshake, reliable; UDP: fast, connectionless
IP & ARP L3 Network — — Logical routing & MAC resolution ARP maps known IP to unknown MAC; RARP does reverse
