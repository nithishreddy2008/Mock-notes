CUET UG · MATHEMATICS · VECTORS & 3D GEOMETRY

DOT (scalar) — a · b

a · b = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃
Output: a number · Zero ⇔ perpendicular (θ = 90°)
Angle: cos θ = a·b / (|a||b|)
Projection of a on b: (a·b)/|b| — the shadow length
Commutative: a·b = b·a

CROSS (vector) — a × b

|a × b| = |a||b| sin θ; direction by right-hand rule
Output: a vector ⊥ to both · Zero ⇔ parallel (θ = 0°)
Area: parallelogram = |a × b|; triangle = ½|a × b|
Anti-commutative: a × b = −(b × a)
2×2 minors: components come from cofactor expansion with î, ĵ, k̂

SCALAR TRIPLE — [a b c]

[a b c] = a · (b × c) = det of the 3×3 of components
Output: a number · |value| = volume of the parallelepiped
Zero ⇔ coplanar — the flatness test
Dot-cross swap: a·(b×c) = (a×b)·c; any two swap = sign flip
Volume of tetrahedron: (1/6)|[a b c]|

Lines in 3D

Vector equation: r = a + λ b — point a, direction b
Cartesian: (x−x₁)/l = (y−y₁)/m = (z−z₁)/n
Direction cosines: l, m, n with l² + m² + n² = 1; direction ratios only need proportionality
Angle between lines: cos θ = |b₁·b₂|/(|b₁||b₂|)
Skew lines: not parallel, never meet; SD = |(a₂−a₁)·(b₁×b₂)| / |b₁×b₂|
Parallel lines: SD = |(a₂−a₁)×b| / |b|

Planes in 3D

Normal form: r · n̂ = d; cartesian lx + my + nz = d
Through a point, ⊥ to n: (r − a)·n = 0
Angle between planes: angle between normals, cos θ = |n₁·n₂|/(|n₁||n₂|)
Line ⊥ plane angle: sin θ = |b·n|/(|b||n|)
Distance point → plane: |ax₁+by₁+cz₁−d| / √(a²+b²+c²)
Plane through 3 points: fit coefficients from the three position vectors (or triple-product form)

TRAPS THE OPTIONS ARE BUILT AROUND

Dot = 0 means ⊥, cross = 0 means ∥ — swapped, they wreck the verdict
Direction cosines vs ratios: cosines satisfy l²+m²+n² = 1, ratios only proportions
Line-plane angle uses sin, plane-plane uses cos — the trig flip
Cross product anti-commutes — order flips the sign
SD of skew lines needs b₁×b₂ — try the parallel formula and it divides by zero
Distance uses the FULL plane ax+by+cz−d — sign does not matter inside |·|
