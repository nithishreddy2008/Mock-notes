CUET Invariants & Fatal Traps
Algorithm State Guarantee After Pass k
Bubble Sort Last $k$ elements are in their final sorted positions.
Selection Sort First $k$ elements are in their final sorted positions.
Insertion Sort First $k+1$ elements are sorted among themselves (not globally final).
Quick Sort Pivot element is strictly in its final sorted position.
Bubble Max Swaps: n(n - 1) / 2
Selection Max Swaps: n - 1 (Linear!)
Merge Sort Aux Space: O(n)
Trap 1: Insertion Sort State After Pass k Students assume $A[0 \dots k]$ are in their final positions. FALSE! An element smaller than all of them appearing later will displace them.
Trap 2: Quick Sort Worst-Case Trigger Already sorted array with first or last element as pivot leads to unbalanced tree of depth $O(n)$, triggering $O(n^2)$ time!
