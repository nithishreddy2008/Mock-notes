Master Synthesis Mindmap: Pandas Series & DataFrames Foundations

CUET UG Computer Science (Code 308) · Complete Architectural Blueprint of 1D & 2D Tabular Structures

Comprehensive Mindmap
1
Pandas Series (1D Array)
• Nature: 1D labeled array; homogeneous data types.
• Mutability: Value mutable, size immutable.
• Core Attributes: .values (NumPy array), .index (labels), .dtype, .shape (n,), .ndim = 1, .size, .empty.
• Default Index: 0 to $n-1$ if omitted.
2
Series Creation & Alignment
• Sources: Python list, 1D ndarray, scalar (replicated), dict (keys become index labels).
• Index Alignment: Binary math aligns by Index Label, NOT position. Unmatched labels become NaN (float64).
• Fill Value: s1.add(s2, fill_value=0) preserves numbers.
3
DataFrame Structure (2D)
• Nature: 2D tabular heterogeneous structure; spreadsheet model.
• Mutability: Both value & size mutable.
• Core Attributes: .axes [rows, cols], .columns, .index, .shape (r, c), .size r×c, .dtypes, .T (transpose).
4
DataFrame Constructors
• Dict of Lists: Keys become column names. All lists MUST be equal length (or ValueError).
• Dict of Series: Series can have unequal lengths; missing index entries automatically become NaN!
• 2D ndarray: Custom row/column names passed via index and columns parameters.
5
Indexing & Slicing Invariants
• loc[row, col]: Label-based. INCLUDES stop label! ('a':'c' includes 'c').
• iloc[row, col]: Integer-based. EXCLUDES stop index! (0:3 includes 0, 1, 2).
• Selection: df['Col'] returns Series; df[['C1', 'C2']] returns DataFrame.
6
Inspection & Manipulation
• head(n): First $n$ rows (default $n=5$).
• tail(n): Last $n$ rows (default $n=5$).
• Column Add/Drop: df['New'] = val adds; del df['Col'] or df.drop('Col', axis=1) removes.
• Boolean Masking: df[df['A'] > 50] filters rows.
