1. Young's Double Slit (YDSE)
Two-Source Interference
Path Diff: Δx = y·d / D | Fringe Width: β = λ·D / d
Bright: y_n = n·λ·D / d | Dark: y_n' = (n - ½)·λ·D / d
  • Equal Fringe Width: All interference fringes (bright and dark) possess strictly identical widths: $\beta = \lambda D / d$.
  • Angular Fringe Width: $\theta = \beta / D = \lambda / d$ is completely independent of screen distance $D$.
  • Medium Effect: In liquid of refractive index $\mu$, wavelength compresses ($\lambda' = \lambda / \mu$), so fringe width decreases: $\beta' = \beta / \mu$.

2. Single Slit Diffraction
Central Maxima Width
Minima: a·sin θ = n·λ | Sec Max: a·sin θ = (n + ½)·λ
Central Max Width: β₀ = 2λD / a = 2β (Twice secondary!)
  • Central Maximum Width: The central bright band is twice as wide as any secondary maximum: $\beta_0 = 2 \beta = 2 \lambda D / a$.
  • Rapid Intensity Fall: Unlike interference where all fringes have equal brightness, diffraction intensity plummets: $I_0 \to I_0 / 22 \to I_0 / 61$.
  • Slit Narrowing Effect: As slit width $a$ is reduced, the central maximum spreads out wider ($\beta_0 \propto 1/a$).

3. Polarization & Brewster
Transverse Nature Proof
Malus's Law: I = I₀ · cos² θ
Brewster's Law: tan i_p = μ | i_p + r_p = 90°
  • Transverse Proof: Polarization can *only* occur in transverse waves; longitudinal sound waves cannot be polarized!
  • Malus's Law: When completely polarized light of intensity $I_0$ passes through an analyzer tilted at angle $\theta$, transmitted intensity is $I = I_0 \cos^2\theta$.
  • Brewster's Angle: At Brewster angle incidence $i_p$, reflected and refracted rays are mutually perpendicular ($i_p + r_p = 90^\circ$). The reflected beam is completely polarized with vibrations perpendicular to the plane of incidence.
