DIFFERENTIAL EQUATIONS
CUET UG MATHEMATICS

Order & Degree

Order: the highest derivative in the equation
Degree: the power of that highest derivative — polynomial only
Not defined: radicals or fractions of derivatives, like (1 + y'²)^(3/2)
Clear first: simplify the equation before reading powers

General vs Particular

General: the whole curve family, constants A, B, C… alive
Particular: one member — constants fixed by given conditions
Verify: differentiate the candidate, substitute, expect an identity
Signature: y = A eˣ + B e⁻ˣ always solves y'' − y = 0

Variable Separable

Shape: dy/dx = f(x) · g(y) — variables already split
Move: all-y with dy, all-x with dx, integrate both sides
Example: dy/dx = xy/(1+x²) → ln|y| = ½ ln(1+x²) + C
e^(x+y) case: split the exponent, then separate

Homogeneous (ratio-shaped)

Shape: dy/dx = F(y/x) — every term same total degree
Test: F(λx, λy) = F(x, y)
Move: y = vx makes dy/dx = v + x dv/dx — then separable
Finish: integrate in v, x, then substitute back y = vx

Linear Equations + IF

Shape: dy/dx + P y = Q (P, Q functions of x)
Engine: IF = e^(∫P dx); then y · IF = ∫ Q · IF dx + C
Example: dy/dx + y/x = x² → IF = x → y = x³/4 + C/x
Flipped form: dx/dy + P x = Q — same engine in y

Choosing the Rung (reflexes)

Product of x-part and y-part? separable
Ratio-shaped, same-degree terms? homogeneous, y = vx
y to power 1 with a coefficient? linear, build the IF
Stuck? check the shape again — three rungs cover the syllabus
