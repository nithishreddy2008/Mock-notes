1. Taxonomy & Boundaries
Foundations
Order: Highest derivative order n. Always defined.
Degree: Power of highest derivative when polynomial in derivatives. Undefined for $e^{y'}, sin(y'), ln(y')$.
Radicals: Must clear fractional powers before reading degree: $y'' = √(1 + y'2) ⇒$ Order 2, Degree 2.
Formation: Differentiate $n$ times to eliminate $n$ arbitrary constants: $y = mx ⇒ xy' - y = 0$.
2. Variable Separable Engine
Method 1
Standard Form: h(y) dy = g(x) dx ⇒ Integrate both sides.
Constant Placement: Introduce $+ C$ on one side only (usually RHS) during integration.
Reducible Form: dy/dx = f(ax + by + c). Put u = ax + by + c, yielding separable DE in $u$ and $x$.
Example: $dy/dx = (x+y)^2 ⇒ ∫ \frac{du}{1 + u^2} = x + C ⇒ \tan^{-1}(x+y) = x + C$.

3 Canonical Solver Methods
3. Homogeneous Equations
Method 2
Condition: $f(λ x, λ y) = λ^0 f(x, y)$, or $dy/dx = F(y/x)$.
Type 1 Substitution: y = v·x ⇒ $dy/dx = v + x(dv/dx)$. Separates into $\frac{dv}{F(v) - v} = \frac{dx}{x}$.
Type 2 Inversion: For functions of $x/y$ (e.g. $e^{x/y}$), write $dx/dy = G(x/y)$ and put x = v·y.
Golden Shortcut: Homogeneous DE general solution curves are always self-similar radial rays from the origin.
4. Linear DE & Integrating Factor
Method 3
Leibniz Form: dy/dx + P(x)y = Q(x). Divide leading coefficients to ensure $dy/dx$ coeff is $1$!
Integrating Factor: IF = e^(∫ P dx). Solution: $y · \text{IF} = ∫ (Q · \text{IF}) dx + C$.
Log Identity Reflex: $e^{-ln x} = 1/x$; $e^{2 ln x} = x^2$; $e^{ln(sec x)} = sec x$.
Dual Type: $dx/dy + P(y)x = Q(y) ⇒ \text{IF} = e^{∫ P(y) dy} ⇒ x · \text{IF} = ∫ (Q · \text{IF}) dy + C$.
General Solution has n constants; Particular Solution has 0 constants
Always check for dy/dx coeff = 1 before computing IF
Use y = vx for dy/dx = F(y/x); use x = vy for dx/dy = G(x/y)
