Master Synthesis Mindmap: Data Visualization with Pyplot

Comprehensive knowledge taxonomy across Chart Types, Styling, Annotations, and File Output

CUET Code 308 · Syllabus Mindmap
1. Chart Typologies
  • plt.plot(x, y): Continuous line plots & curves.
  • plt.bar(x, height, width): Vertical bar charts.
  • plt.barh(y, width, height): Horizontal bar charts.
  • plt.hist(x, bins): Continuous frequency histograms.
  • plt.scatter(x, y, s, c): Point coordinate scatters.
2. Line & Marker Styling
  • Color codes: 'r', 'g', 'b', 'c', 'm', 'y', 'k', 'w'.
  • Linestyles: '-' (solid), '--' (dashed), '-.' (dash-dot), ':' (dotted).
  • Marker styles: 'o' (circle), 's' (square), '^' (triangle), '*' (star), '+'.
  • Format string shorthand: 'r--o' (red, dashed, circle).
3. Canvas Annotations
  • plt.title('Text', fontsize, color): Main canvas title.
  • plt.xlabel() and plt.ylabel(): Axis labels.
  • plt.legend(loc='best'|'upper right'): Key labels.
  • plt.grid(True, linestyle=':', alpha=0.5): Background grid.
4. Axis Limits & Ticks
  • plt.xlim(min, max) and plt.ylim(min, max).
  • plt.xticks(ticks, labels, rotation=45): Custom marks.
  • plt.yticks(ticks, labels): Vertical tick calibration.
  • Tick label rotation prevents text crowding.
5. Multi-Series & Subplots
  • Multiple bars: Shift X positions: x + width.
  • Stacked bars: Use bottom=y1 parameter.
  • plt.subplot(nrows, ncols, index): 1-indexed grid.
  • fig, (ax1, ax2) = plt.subplots(1, 2): OO interface.
6. File Output & State
  • plt.show(): Renders window; resets canvas state!
  • plt.savefig('file.png', dpi=300, bbox_inches='tight').
  • Must call savefig() before show()!
  • Supported formats: PNG, PDF, SVG, JPG, EPS.
