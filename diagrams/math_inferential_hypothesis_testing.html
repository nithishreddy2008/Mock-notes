Section B2 Applied Math
1. The 5-Step Hypothesis Testing Protocol & Error Matrix
1
State Hypotheses: Null H₀: μ = μ₀ (status quo / no effect) vs Alternative H₁: μ ≠ μ₀ (two-tailed) or μ > μ₀ / μ < μ₀ (one-tailed).
2
Set Significance Level (α): Choose probability of Type I error (typically α = 0.05 or 0.01).
3
Calculate Test Statistic: Compute standard score: t_calc = (x̄ - μ₀) / (s / √n).
4
Determine Critical Value & Rejection Region: Identify t_crit at df = n - 1. Two-tailed reject if |t_calc| > t_crit.
5
State Statistical Inference: If t_calc falls in critical region, reject H₀ at α level; else fail to reject H₀.
Decision Outcomes: Truth vs Statistical Verdict
Reality \ Decision Fail to Reject H₀ (Accept Status Quo) Reject H₀ (Declare Significant Effect)
H₀ is Actually TRUE Correct Decision (Prob = 1 - α) Type I Error (α) — False Positive
H₀ is Actually FALSE Type II Error (β) — False Negative Correct Decision: Power (1 - β)
CUET Trap Alert (Never "Accept" H₀): When |t_calc| ≤ t_crit, we say "we fail to reject H₀" or "insufficient evidence to reject H₀". We never claim H₀ is proven true; we merely observe that the sample does not contradict it.
2. Student's t-Statistic, Degrees of Freedom & Central Limit Theorem
One-Sample t-Statistic & Sample Variance
t = (x̄ - μ₀) / (s / √n) = (x̄ - μ₀) / SE(x̄)
s² = Σ (xᵢ - x̄)² / (n - 1), quad df = n - 1
Where x̄ is sample mean, μ₀ is hypothesized population mean, s is sample standard deviation (Bessel's corrected denominator n - 1), n is sample size (< 30), and df = n - 1 is degrees of freedom.
Attribute Small Sample t-Test Large Sample Z-Test (CLT)
Sample Size Condition Small sample: n < 30 Large sample: n ≥ 30
Population Variance (σ²) Unknown (estimated by sample s) Known or unknown (CLT applies)
Distribution Curve Shape Heavier tails, lower peak; depends on df Standard normal bell curve Z ~ N(0, 1)
Asymptotic Behavior As df = n - 1 → ∞, t-curve approaches Z-curve Standard normal z = (x̄ - μ) / (σ / √n)
Central Limit Theorem (CLT) Axiom: For any arbitrary parent population with mean μ and variance σ², the distribution of the sample mean x̄ tends asymptotically toward a normal distribution N(μ, σ²/n) as sample size n grows (n ≥ 30), regardless of the shape of the population!
CUET Trap Alert (Bessel's Correction n vs n-1): Dividing by n gives the biased sample variance; to obtain the unbiased estimator s² for the t-test, the denominator must strictly be n - 1. Degrees of freedom for one group is always df = n - 1.
