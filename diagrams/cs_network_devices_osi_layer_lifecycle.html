Physical Layer Layer 1 (Bits)

Repeater2-Port

Regenerates and amplifies electrical/optical signals attenuated by distance. Does not filter or inspect packet contents.

Hub (Passive / Active)Multi-Port

Multiport repeater. Broadcasts incoming bits to all other ports blindly. All ports share a single collision domain.

Data Link Layer Layer 2 (Frames)

Bridge2-Port Segmenter

Filters and forwards frames based on physical MAC addresses. Segregates LAN into separate collision domains.

SwitchMulti-Port Bridge

Maintains dynamic MAC Address Table. Provides dedicated collision domain per port; forwards unicast frames directly to destination.

Network Layer Layer 3 (Packets)

RouterInter-Network

Routes packets across disparate networks using logical IP addresses. Maintains dynamic routing tables (OSPF, BGP).

Broadcast IsolationBoundary

Crucial property: Routers block broadcast packets, segregating networks into distinct, manageable broadcast domains.

Upper Layers Layers 4–7

GatewayTranslator

Protocol converter connecting completely incompatible network architectures (e.g. TCP/IP to SNA). Translates packet payloads.

Modem (Mod/Demod)Analog ↔ Digital

Modulates digital computer signals into analog frequencies for telephone/cable lines, and demodulates returning analog carrier waves.
