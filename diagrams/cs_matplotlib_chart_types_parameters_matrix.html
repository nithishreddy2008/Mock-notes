Chart Type Pyplot Function Primary Analytical Purpose Key Parameters & Flags CUET High-Yield Trap
Line Plot plt.plot(x, y) Display trends, continuous temporal changes, and mathematical curves. color, linestyle ('-', '--', ':'), linewidth, marker, markersize, label. Passing single list plt.plot([1, 4, 9]) uses it as Y-values; X defaults to 0, 1, 2!
Vertical Bar Chart plt.bar(x, height) Compare discrete discrete categorical metrics side-by-side. width (default 0.8), color, edgecolor, bottom (for stacking), align. For multiple bar charts, X-coordinates must be manually shifted by bar width!
Horizontal Bar Chart plt.barh(y, width) Compare categories with long text labels that crowd vertical axes. height (default 0.8), left (for horizontal stacking), color, edgecolor. Arguments are flipped: 1st argument is vertical Y position; 2nd is horizontal width.
Histogram plt.hist(x) Visualize frequency distributions of continuous numerical datasets. bins (default 10 or sequence), range, density=True, cumulative=True, edgecolor. A histogram plots frequency over binned intervals, NOT discrete categories like a bar chart!
Scatter Plot plt.scatter(x, y) Detect correlation, clustering, and relationships between two continuous variables. s (marker size in points^2), c (color sequence), marker, alpha (transparency), cmap. Parameter for size is strictly s (not size); parameter for color is c.
