Reasoning Core Syllabus
1. Deductive Syllogisms
Venn Logic
A-Type: All A are B
Universal Affirmative. Circle A is completely subsumed within Circle B. Does NOT imply "All B are A".
Valid Converse: Some B are A
E-Type: No A is B
Universal Negative. Complete disjoint separation between sets A and B. Fully symmetrical.
Valid Converse: No B is A
I-Type: Some A are B
Particular Affirmative. Overlapping intersection. Does NOT guarantee "Some A are not B".
Valid Converse: Some B are A
Either-Or Complementary Pairs
Two individually unprovable conclusions share identical Subject-Predicate: (All + Some Not) or (Some + None).
Either Concl I or Concl II follows
2. Relational Hierarchies
Family Trees
Generation Level Mapping
Grandparents (+2) → Parents/Uncles (+1) → Self/Siblings (0) → Children (-1) → Grandchildren (-2).
Vertical = Gen; Horizontal = Siblings
Gender Neutrality Rule
Never deduce gender from proper names (e.g. Kiran, Robin). Mark [+] for male, [-] for female, [?] until proven.
Spouses: [A] = [B] (Double Bond)
Paternal vs Maternal Roots
Father's side: Paternal Uncle/Aunt. Mother's side: Maternal Uncle/Aunt. Uncle's child = Cousin (never nephew).
Nephew/Niece = Sibling's child
Coded Blood Chains
Decode symbols right-to-left or step-by-step: P + Q × R ÷ S. Map generation shifts algebraically.
A + B = Father (+1); A × B = Brother (0)
3. Spatial & Directional
Positional Geometry
Circular Seating Concord
Facing Center: Left = Clockwise, Right = Counter-Clockwise. Facing Outward: Directions invert exactly.
Facing Center: Left = CW; Right = CCW
Linear Row Constraints
Facing North: Left = West, Right = East. Facing South: Left = East, Right = West. Anchor definite end-seats first.
Extreme Ends = Non-Negotiable Anchors
8-Point Cardinal Compass
N, S, E, W + NE, NW, SE, SW. Right turn = 90° clockwise; Left turn = 90° counter-clockwise.
Two Consecutive Turns (R+R) = 180° Flip
Pythagorean Displacement
Shortest aerial distance from starting point to destination using right-angled triangle vectors.
Displacement d = √(Δx² + Δy²)

Reasoning Protocol

Algorithmic 4-Step Workflow for Logical Precision

STAGE 01
Diagram Before Eyeing
Sketch physical Venn circles, tree nodes, or compass axes before reading options.
STAGE 02
Anchor Certainty First
Lock clues that provide absolute positions (e.g., "A sits 2nd from right end").
STAGE 03
Case Branching
If ambiguous, run parallel Case 1 and Case 2; one branch will rapidly invalidate.
STAGE 04
Definite Deduction
Ensure the conclusion holds across all valid Venn diagrams without speculation.
