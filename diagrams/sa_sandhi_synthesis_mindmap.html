संस्कृत-सन्धि-प्रकरणम् : सर्वाङ्गीणं महामानचित्रम् (Synthesis Mindmap)

CUET UG संस्कृतम् (Code 325) · अच्-हल्-विसर्ग-सन्धयः, पाणिनीय-सूत्राणि, अपवादाः परीक्षा-सूत्राणि च

चित्रम् ३ · Master Mindmap
१. अच्-सन्धिः (स्वर-सन्धयः · ८ भेदाः) स्वरयोः सन्निधिः
  • • सवर्णदीर्घः: अकः सवर्णे दीर्घः → विद्या + आलयः = विद्यालयः, भानु + उदयः = भानूदयः
  • • गुण-सन्धिः: आद्गुणः (अ/आ + इ/उ/ऋ) → उपेन्द्रः (ए), सूर्योदयः (ओ), देवर्षिः (अर्)
  • • वृद्धि-सन्धिः: वृद्धिरेचि (अ/आ + एच्) → तथैव (ऐ), जलौघः (औ), महौदार्यम् (औ)
  • • यण्-सन्धिः: इको यणचि (इक् + असवर्ण अच्) → यदि + अपि = यद्यपि, अनु + अयः = अन्वयः
  • • अयादि / पूर्वरूपम्: एचोऽयवायावः (नयनम्, गायकः, पवनः, पावकः) / एङः पदान्तादति (हरेऽव, विष्णोऽव)
  • • पररूप / प्रकृतिभावः: एङि पररूपम् (प्रेजते, उपोषति) / प्लुतप्रगृह्या... (हरी एतौ, लते एते)
२. हल्-सन्धिः (व्यञ्जन-सन्धयः · ८ भेदाः) व्यञ्जन-विकारः
  • • श्चुत्व-सन्धिः: स्तोः श्चुना श्चुः (स्/तवर्ग + श्/चवर्ग = श्/चवर्ग) → रामश्शेते, सच्चित्, शार्ङ्गिञ्जयः
  • • ष्टुत्व-सन्धिः: ष्टुना ष्टुः (स्/तवर्ग + ष्/टवर्ग = ष्/टवर्ग) → रामष्षष्ठः, तट्टीका, उड्डीनः
  • • जश्त्वम्: झलां जशोऽन्ते (पदान्ते झल् → ३य वर्णः) → वागीशः, जगदीशः, सुबन्तः, षडाननः
  • • चर्त्वम्: खरि च (झल् + खर् → १म वर्णः) → सद् + कारः = सत्कारः, उद् + पन्नः = उत्पन्नः
  • • अनुस्वारः / परसवर्णः: मोऽनुस्वारः (हरिं वन्दे) / अनुस्वारस्य ययि परसवर्णः (शङ्का, चञ्चुः)
  • • तोर्लि / छत्वम्: तोर्लि (तत् + लयः = तल्लयः) / शश्छोऽटि (तत् + शिवः = तच्छिवः)
३. विसर्ग-सन्धिः (विसर्गस्य रूपाणि) रुत्व-उत्व-सत्व-लोपाः
  • • उत्व-सन्धिः: अतो रोरप्लुतादप्लुते (अ + : + अ → ओऽ) → शिवोऽर्च्यः, कोऽपि, प्रथमोध्यायः
  • • हशि च उत्वम्: हशि च (अ + : + ३/४/५/यवरलह → ओ) → रामो गच्छति, शिवो वन्द्यः
  • • रुत्वम्: ससजुषो रुः (पदान्त सकारस्य रुः, रेफः) → मुनिः + अयम् = मुनिरयम्, गुरुः + जयति = गुरुर्जयति
  • • सत्व-सन्धिः: विसर्जनीयस्य सः (विसर्ग + खर्) → नमः + ते = नमस्ते, कः + चित् = कश्चित्
  • • रो रि & ढ्रलोपः: रो रि (र् + र् → पूर्व रेफलोपः, पूर्वस्वरस्य दीर्घः) → पुनर् + रमते = पुनारमते
  • • विसर्ग-लोपः: भोभगोअघोअपूर्वस्य... / एतत्तदोः सुलोपोऽकोरनञ्पे... → सः गच्छति = स गच्छति
४. CUET Fatal Traps & परीक्षा-सूत्राणि उच्च-भ्रामकाः अंशाः
  • • Trap १ (पूर्वरूप vs अयादि): हरे + अव = हरेऽव (पूर्वरूपम्); किन्तु प्रभो + एहि = प्रभवेहि (अयादिः)!
  • • Trap २ (प्रकृतिभावः): 'हरी एतौ', 'विष्णू इमौ', 'गङ्गे अमू' — ईदूदेद् द्विवचनं प्रगृह्यम्, सन्धिः न भवति!
  • • Trap ३ (सः / एषः विसर्ग-लोपः): 'सः + पठति' = स पठति ('अ' भिन्ने व्यञ्जने विसर्ग-लोपः, 'सः अपठत्' = सोऽपठत्)!
  • • Trap ४ (रो रि रेफलोपः): 'पुनर् + रमते' = पुनारमते (दीर्घः अनिवार्यः, 'पुनरमते' अशुद्धम्)!
  • • Trap ५ (पररूप-अपवादः): प्र + एजते = प्रेजते, उप + ओषति = उपोषति (वृद्धिः न भवति, पररूपं भवति)!
  • • Trap ६ (जश्त्व-विच्छेद-भ्रमः): 'दिगम्बरः' = दिक् + अम्बरः (न तु 'दिग् + अम्बरः'); 'अजन्तम्' = अच् + अन्तम्!
