DNA Structure & Packaging

Double helix (Watson + Crick 1953): 2 nm wide, one turn 3.4 nm with ~10 bp; strands antiparallel 5'→3' vs 3'→5'
Base pairing: A=T (2 H-bonds), G≡C (3 H-bonds); Chargaff: A = T and G = C
Nucleosome: ~200 bp wound 1¾ turns round a histone octamer (H2A, H2B, H3, H4 ×2) + linker H1
Prokaryotes: supercoiled DNA in the nucleoid — basic proteins, no histones

The Search for Genetic Material

Griffith 1928: heat-killed S + live R Streptococcus killed mice — a "transforming principle" moved across
Avery 1944: protease + RNase did not stop transformation; DNase did → the transformer is DNA
Hershey-Chase 1952: ³²P (DNA) entered cells, ³⁵S (protein) stayed in the supernatant
Verdict: DNA, not protein, carries heredity

Replication

Semi-conservative: every daughter duplex = one old strand + one new strand
Meselson-Stahl 1958: ¹⁵N → ¹⁴N; generation 1 all hybrid, generation 2 half light + half hybrid
Machinery: origin starts it; DNA pol builds 5'→3'; lagging strand = Okazaki pieces; ligase seals
Taylor: ³H-thymidine in Vicia faba roots — chromosomes replicate semi-conservatively too

Transcription & RNA Types

Transcription unit: promoter (start) + structural gene + terminator (stop)
Template strand is read; the coding strand matches the RNA (with U in place of T)
Bacteria: RNA pol + sigma factor (initiation) + rho (termination); eukaryotes: Pol I rRNA, Pol II mRNA, Pol III tRNA
hnRNA processing: 5' cap + 3' poly-A tail + introns spliced out; mRNA message, tRNA adapter, rRNA scaffold

Genetic Code & Translation

Code properties: triplet, degenerate, unambiguous, universal, commaless, colinear
Counts: 64 codons — 61 sense + 3 stop; AUG = start (Met); UAA/UAG/UGA stop
tRNA adapter: anticodon at one end, amino-acid acceptor arm at the other; charged by aminoacyl-tRNA synthetase
Translation: initiation → elongation → termination; polysome = many ribosomes on one mRNA

Regulation, HGP & Fingerprinting

Lac operon: no lactose → repressor on operator → OFF; lactose present → repressor lifts → ON
HGP 1990–2003: ~3 billion bp sequenced, ~20,000 genes found, <2% of genome codes for proteins
Fingerprinting: satellite DNA + VNTR repeats give polymorphism — the basis of a unique profile
Steps: isolate → digest/amplify → gel → Southern blot → labelled probe → autoradiogram

COMMON ERRORS & TRAPS

³²P = DNA, ³⁵S = protein. Students swap the labels — P sits in DNA, S sits in cysteine/methionine
Repressor binds the operator, not the promoter; 61 codons code for amino acids, 3 do not
Splicing is eukaryote-only in the NCERT story; a nucleosome wraps ~200 bp, never 2,000
