Spatial Algebra & Coordinate Lines System
Branch 1
Vector Operations & Components
Unit Vector: â = a / |a| ; |â| = 1
Position Vector: r = x î + y ĵ + z k̂ ; |r| = √(x² + y² + z²)
Displacement: AB = (x₂-x₁)î + (y₂-y₁)ĵ + (z₂-z₁)k̂
Section Formula: Internal: r = (m b + n a)/(m+n) | External: (m b - n a)/(m-n)
Collinearity: b = λ a ⟺ a₁/b₁ = a₂/b₂ = a₃/b₃
Branch 2
Dot & Cross Products
Scalar (Dot): a · b = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃
Projection of a on b: proj = (a · b) / |b| = a · b̂
Vector (Cross): a × b = |a||b| sin θ n̂ = det[î, ĵ, k̂; a₁,a₂,a₃; b₁,b₂,b₃]
Geometric Area: Triangle = ½|a × b| ; Parallelogram = |a × b| or ½|d₁ × d₂|
Lagrange Identity: |a × b|² = |a|²|b|² - (a · b)²
Branch 3
Direction Cosines & Ratios (3D)
Identity (DCs): l² + m² + n² = 1 ; sin²α + sin²β + sin²γ = 2
DCs from DRs: l = ± a/√(a²+b²+c²), m = ± b/√(Σa²), n = ± c/√(Σa²)
Axes DCs: x-axis: (1, 0, 0) ; y-axis: (0, 1, 0) ; z-axis: (0, 0, 1)
Angle between DRs: cos θ = |a₁a₂ + b₁b₂ + c₁c₂| / (√(Σa₁²) √(Σa₂²))
Perp / Parallel: Perp: a₁a₂ + b₁b₂ + c₁c₂ = 0 | Parallel: a₁/a₂ = b₁/b₂ = c₁/c₂
Branch 4
3D Lines & Spatial Separation
Vector Equation: r = a + λ b (Cartesian: (x-x₁)/a = (y-y₁)/b = (z-z₁)/c)
Skew Lines SD: d = |(b₁ × b₂) · (a₂ - a₁)| / |b₁ × b₂|
Parallel Lines SD: d = |b × (a₂ - a₁)| / |b|
Intersection Test: (b₁ × b₂) · (a₂ - a₁) = 0 ⟺ d = 0 (Coplanar lines)
Standard Trap: Ensure numerators have +1 coefficient for x, y, z!
