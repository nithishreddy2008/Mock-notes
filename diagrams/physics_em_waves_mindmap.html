1. Displacement Current (Id)
Maxwell Correction
Id = ε₀(dΦE/dt) = ε₀ A(dE/dt) | ∮ B·dl = μ₀(Ic + Id)
  • Continuity Principle: Conduction current in wires transfers into displacement current in dielectric/vacuum gaps; Ic = Id.
  • Source of Magnetism: Time-varying electric flux generates magnetic fields just as moving charges do.
  • DC Saturation: For constant electric field, dE/dt = 0, so Id = 0 (capacitor completely blocks DC).
2. Maxwell's Unified Equations
Field Equations
∮ E·dA = q/ε₀ | ∮ B·dA = 0 | ∮ E·dl = -dΦB/dt
  • Gauss's Law for E: Electric charges are scalar sources and sinks of electric fields.
  • Gauss's Law for B: Net magnetic flux through closed surface is zero; isolated monopoles do not exist.
  • Faraday-Lenz Law: Time-varying magnetic flux generates a circulating, non-conservative electric field.
3. Transverse Propagation & Speed
c = E₀/B₀
c = 1/√(μ₀ ε₀) = ω/k = E₀/B₀ | k ∥ (E × B)
  • Transverse Polarization: E and B vibrate mutually perpendicular to each other and to direction of propagation k.
  • In-Phase Oscillations: Both fields reach crests, troughs, and zero nodes simultaneously in space and time.
  • Material Medium: Wave speed v = 1/√(μ ε) = c / √(μr εr) = c / n (refractive index n = √(μr εr)).
4. Energy Density & Momentum
Poynting Flux
u_avg = ½ ε₀ E₀² = B₀²/(2μ₀) | S = (1/μ₀)(E × B) | p = U/c
  • Equipartition of Energy: Total average energy divides identically between electric and magnetic fields.
  • Intensity (I): Average power per unit area: I = u_avg · c = ½ ε₀ c E₀².
  • Radiation Pressure: Prad = I/c (complete absorption) and Prad = 2I/c (complete normal reflection).
