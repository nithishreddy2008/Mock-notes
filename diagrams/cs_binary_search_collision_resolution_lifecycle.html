C Load Factor & Rehashing
Load Factor ($\lambda$):
$\lambda = \frac{N}{m}$ where $N = \text{keys stored}$, $m = \text{table size}$.
• Open Addressing: $\lambda \le 1.0$ strictly.
• Chaining: $\lambda$ can exceed $1.0$ (chains grow).
Dynamic Rehashing:
When $\lambda > 0.70$ (or $0.75$), performance degrades. The table doubles size ($m' = 2m$), chooses next prime, and re-computes all hashes.
Python `dict` Architecture:
CPython uses compact hash tables with open addressing (modified pseudo-random perturbation) to eliminate primary clustering. Resizes at $\lambda > 0.66$.
Midpoint Calculation Overflow Trap:
Writing mid = (low + high) // 2 can cause integer overflow in languages with fixed integer widths! Safe formula: mid = low + (high - low) // 2.
